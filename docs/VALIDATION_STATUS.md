# 현재 검증 상태

확인일: 2026-09-10

이 저장소는 개발 중인 소스입니다. `package.json`의 `0.7.2` 표기와 고정 배포 ZIP이 같더라도 `main`의 코드가 ZIP과 동일하다는 뜻은 아닙니다. 아래 수치는 AI를 연결하지 않은 로컬 처리 결과이며, 모든 문항의 수식·지문·표·성취기준이 정확하다고 승인한 결과가 아닙니다.

## 이번 업로드에 포함한 사항

- 앱 하단에 `제작자: 여광재(온양고등학교)`와 `무단 전제 및 복제 금지`를 표시합니다. 데이터·HWPX·KaTeX 출처 표시는 유지합니다.
- 이전 로컬 작업의 표·상자, 선택지 보존, 굵게·밑줄 편집, 수식 복원, 문제함 개선 코드를 저장소에 반영합니다.
- 문항 번호가 양쪽 단에 모두 나타나지 않는 페이지도 텍스트의 빈 세로 영역을 측정해 단을 찾습니다. 짧은 상단 문항과 큰 과목명 때문에 단을 잘못 나누던 사례를 보정했습니다.
- 원문 글꼴의 이름·코드·윤곽 지문을 모두 대조한 수식 기호와 옛한글 복원을 추가했습니다. 글꼴 파일 자체는 포함하지 않습니다.
- 문항 번호 위에 걸친 수식 조각을 발문으로 덮어쓰지 않도록 보존합니다.
- 여러 페이지에 걸친 공통 지문 탐색과 다음 지문 세트 앞에서의 캡처 종료를 보정했습니다. 세트 전체의 의미·범위가 완전한지는 별도 수동 대조가 필요합니다.

## 자동 검사 결과

- 회귀 테스트: 104개 중 **103개 통과, 1개 선택적 실제 PDF 테스트 생략**, 실패 0개. 생략된 테스트는 별도 `MUNHANG_SAMPLE_SCIENCE` 입력이 필요합니다.
- TypeScript 검사와 웹 빌드 통과.
- 테스트용 임시 데이터 폴더를 이용한 로컬 문제함 저장·재시작·다른 출처 접근 거부 통과. 실제 사용자 문제함과 API 키는 사용하지 않았습니다.
- 예시 PDF의 분석·검토 저장·다시 열기는 외부 API 요청 없이 검사했습니다.

| 로컬 재검사 | 수학 | 국어 |

| 페이지 | 12 | 16 |
| 문항 수 / 번호 순서 | 30 / 1–30 유지 | 45 / 1–45 유지 |
| 검증된 글꼴 지문으로 복원한 문자 | 1,385 | 19 |

| 검토 파일 저장·재열기 일치 | 통과 | 통과 |

**문자 보존은 수식 의미 보존과 다릅니다.** 문자들이 모두 있어도 분자·분모, 위·아래첨자, 공통 지문 소속이 틀릴 수 있습니다. 표·상자의 개수도 정답 개수와 대조한 검출 정확도가 아닙니다. 자동 경고가 없는 문항에도 오류가 남을 수 있습니다.

## 아직 완료하지 않은 수동 대조

- 수학: 중첩 지수·분수, 극한의 아래첨자, 합 기호의 위·아래 범위, 근호 범위, 선분 위 가로줄, 구간별 함수의 큰 중괄호, 그림 내부 라벨과 본문의 분리. 현재 자동 경고는 1·4·13·15·16·20번에서 발생하지만 검토 대상을 이 여섯 문항으로 한정하면 안 됩니다.
- 국어: 공통 지문의 모든 페이지/단 소속과 침범 여부, 병합 머리글과 일부 작은·중첩 상자, 지문 표시 기호의 범위, 원문 굵게·밑줄 자동 복원.
- 성취기준: 현재 후보 검색 점수는 정확도나 AI 확신도가 아닙니다. 평가 요소 중심 영역 제한과 문항별 정답 대조가 더 필요합니다. 카탈로그는 2022 개정이며, 2015 개정 시험과의 교육과정 일치 정확도는 검증하지 않았습니다.
- 모든 공급자의 실제 유료 비전 API, Windows 실기기 실행, Word/한컴에서의 실제 문서 열기는 이번 검사에 포함하지 않았습니다.
- 이번 업로드 직전의 전체 PDF 재검사는 위 수학·국어 두 파일입니다. README의 과학·영어 검증 기록은 이전 버전에서 실시한 기록이며, 이번 코드에 대한 전체 재검증 완료로 해석하면 안 됩니다.

## 자료와 배포 구분

- 원본 시험지, 문항 전문·캡처 이미지, API 키, 연결 설정, 문제함, 상세 로컬 검토 로그는 GitHub에 올리지 않습니다. 재현용 PDF는 사용 권한이 있는 파일을 각자 준비합니다.
- `scripts/check-pdf-structures.cjs`로 PDF별 구조·문자 보존을 검사할 수 있습니다. 이 검사는 문자 소실의 일부를 탐지할 뿐, 수식이나 매핑의 정답 채점기는 아닙니다.
- `scripts/repackage-0.7.2.py`는 기존 고정 ZIP을 영문 내부 경로와 Windows용 실행 파일로 다시 포장하는 도구입니다. 원본 ZIP은 저장소에 없으므로 별도로 준비해야 합니다. 새 추출 수정이나 이번 제작자 표시는 이 고정 ZIP에 소급 반영하지 않습니다.
- 저장소 소유자의 확인에 따라 공개 상태를 유지해 소스와 검증 문서를 동기화합니다. 문항맵 자체 코드의 MIT 라이선스와 제3자 자료 고지는 그대로 유지합니다. 이번 푸시는 새 릴리스 태그 생성이나 웹사이트 배포를 포함하지 않습니다.
