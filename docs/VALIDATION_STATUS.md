# 현재 검증 상태

확인일: 2026-09-11

현재 버전은 `0.7.5`입니다. 같은 버전의 ZIP을 GitHub 릴리스에 게시하며 기존 릴리스는 보존합니다. 모든 문항의 수식·지문·표·성취기준이 정확하다고 승인한 결과가 아닙니다.

## 0.7.5 — 중앙 목록 구조 표시

- 중앙 목록에서 박스·표를 평문으로 펴던 표시를 제거하고, 오른쪽과 같은 구조 렌더러를 사용합니다. 목록의 compact 옵션은 내용 생략이 아닌 간격 조절에만 사용합니다.
- 줄 수 제한을 제거하고 긴 수식·표에 가로 스크롤을 제공합니다. 미리보기를 선택 버튼 밖에 배치해 표 구조를 유지하며, 문항 번호 버튼과 내용 영역은 키보드로 접근할 수 있습니다.
- 합성 예제에서 중첩 박스·표 머리글·굵게·밑줄·수식·순서를 검사했습니다. 기존 수학 검토 JSON 30문항의 중앙/상세 구조 수가 일치하고, 18번의 두 박스가 양쪽에서 모두 렌더링됩니다. 60회 SSR 렌더링에서 KaTeX 오류는 없었습니다.
- 회귀 테스트 131개, TypeScript와 웹/로컬 빌드 통과. 실제 브라우저의 크기 변경·마우스·터치 조작 검사는 수행하지 않았습니다. 기존 원문·검토 JSON·문제함·API 키는 변경하지 않았고 API 호출도 하지 않았습니다.
- 로컬 ZIP의 95개 항목 CRC·UTF-8 파일명·Mac 실행 권한·필수 파일·개인 자료 제외 검사를 통과했습니다. 압축 해제본의 첫 화면·PDF worker MIME·임시 문제함 저장/재시작·다른 출처 차단도 검사했습니다.

## 0.7.4 — AI 결과 JSON 경로 추가 검증

0.7.3의 아래 PDF 검사는 **무API 추출 경로**의 결과였습니다. 제출된 AI 판독 결과 JSON에서는 별도의 이스케이프 손상이 발견되어 보완했습니다.

- `\bigg`/`\bar`의 JSON 백스페이스 손상, `\to` 등의 탭 손상을 수식 안의 알려진 명령에 한해 복원합니다. `\text{lim}` 조건도 연산자에 붙이고 아래에 표시합니다.
- 수식 시작 직후 줄바꿈과 중복 역슬래시를 처리합니다. 정상 본문 탭, 표·cases·aligned의 행 구분은 보존합니다.
- 제어문자·KaTeX 문법 오류·짝이 맞지 않는 구분자·수식 밖 첨자·분리된 절댓값·긴 발문 전체 중복을 검사합니다. AI 출력이 잘못되면 정상 기존 추출문을 보존하고, 양쪽 모두 오류이면 검토를 요청합니다. 공통 지문의 개별 발문도 검사합니다.
- 전체 회귀 테스트 **130개 통과**, 실패·생략 0개. TypeScript·웹/로컬 renderer 빌드 통과.
- 0.7.4 로컬 ZIP의 95개 항목 CRC·필수 파일·개인 자료 제외·UTF-8 이름·Mac 실행 권한을 검사했습니다. 실제 압축 해제본의 첫 화면·PDF worker MIME·임시 문제함 저장/재시작·출처 차단 검사도 통과했습니다.
- 제출된 수학 JSON 30문항에서 알려진 손상과 원문 대조 수정 10문항을 반영한 **별도 개인 수정본**을 만들었습니다. 30문항 재가져오기·저장 및 목록/상세 60회 렌더링 검사에서 KaTeX 오류 0건입니다. 원본 JSON·캡처 좌표·페이지 이미지·성취기준 코드는 보존했습니다.
- 13·15·16·17·21번의 제어문자·합 수식 경계·중복·극한 피연산식·절댓값 범위는 원문 캡처를 대조해 개인 수정본에서 바로잡았습니다. 이를 문항 번호별 하드코딩이나 임의 의미 추정 규칙으로 앱에 넣지 않았습니다.
- 유료 AI API 호출은 0회입니다. 키·사용자 문제함에 접근하지 않았습니다. 수정본 JSON과 상세 로그에는 시험지 원문이 있으므로 공개 저장소·릴리스에 포함하지 않습니다.

수식 렌더링 통과는 의미 정확도 검사가 아닙니다. 그림 라벨 혼입, 일부 넓은 캡처 범위, 매핑 정확성은 별도 원문 대조가 필요합니다. Windows 실기기·Word/한컴 실행은 검증하지 않았습니다.

## 자동 수정과 최종 승인 구분

- 위에 열거한 수학·국어 구조 오류는 수정하고 재검사했습니다. 그러나 그림 속 A/B/C 등의 라벨과 본문의 완전 분리, 순수 이미지 내용의 무API OCR, 임의 글꼴의 모든 수식 복원은 완료된 기능이 아닙니다.
- 성취기준 후보는 규칙 기반 초안입니다. 국어에는 동일 코드 과다 사용·세트 내 반복 등의 검토 항목이 남습니다. 이는 정확도나 오답 개수가 아니며, 문항별 기준 정답표를 이용한 교사 승인까지 완료한 것이 아닙니다. 다른 과목은 기존 키워드 검색 방식입니다. 카탈로그는 2022 개정이며, 2015 개정 시험과의 교육과정 일치 정확도는 검증하지 않았습니다.
- 화학 11·18번의 수식 배치/그림 선택지는 원본 대조 안내를 유지합니다. 원문 이미지가 보존되어도 편집 가능한 텍스트가 모두 완성됐다는 뜻은 아닙니다.
- DOCX/HWPX의 표·서식·캡처 저장은 자동 검사했지만 수식은 여전히 LaTeX 원문과 캡처로 보존합니다. 웹 KaTeX 표시가 Word/한글의 네이티브 수식 객체로 바뀌는 것은 아닙니다.
- 모든 공급자의 실제 유료 비전 API, Windows 실기기 실행, Word/한컴에서의 실제 문서 열기는 이번 검사에 포함하지 않았습니다.
- 자동 경고 없음은 의미 정확성의 보장이 아닙니다. 원문과 최종 문서를 확인한 뒤 수업 자료로 사용하세요.

## 자료와 배포 구분

- 원본 시험지, 문항 전문·캡처 이미지, API 키, 연결 설정, 문제함, 상세 로컬 검토 로그는 GitHub에 올리지 않습니다. 재현용 PDF는 사용 권한이 있는 파일을 각자 준비합니다.
- `scripts/check-pdf-structures.cjs`로 PDF별 구조·문자 보존을 검사할 수 있습니다. 이 검사는 문자 소실의 일부를 탐지할 뿐, 수식이나 매핑의 정답 채점기는 아닙니다.
- `scripts/repackage-0.7.2.py`는 기존 고정 ZIP을 영문 내부 경로와 Windows용 실행 파일로 다시 포장하는 도구입니다. 원본 ZIP은 저장소에 없으므로 별도로 준비해야 합니다. 새 추출 수정이나 이번 제작자 표시는 이 고정 ZIP에 소급 반영하지 않습니다.
- 저장소 소유자의 요청에 따라 공개 상태를 유지하고 `v0.7.5` 태그에서 최신 로컬 ZIP을 배포합니다. 이후 ZIP 변경도 GitHub 릴리스까지 함께 갱신합니다. 문항맵 자체 코드의 MIT 라이선스와 제3자 자료 고지는 그대로 유지하며 웹사이트 호스팅이나 DMG/EXE 배포는 하지 않습니다.
