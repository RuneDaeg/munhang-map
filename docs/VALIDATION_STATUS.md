# 현재 검증 상태

확인일: 2026-09-12

현재 버전은 `0.7.9`입니다. 같은 버전의 ZIP을 GitHub 릴리스에 게시하며 기존 릴리스는 보존합니다. 모든 문항의 수식·지문·표·성취기준이 정확하다고 승인한 결과가 아닙니다.

## 0.7.9 — 로컬 우선 분석·선택 문항 API 판독

- `runExamAnalysis`에서 AI 연결 조회·전체 문항 판독 단계를 제거했습니다. 저장된 키가 있어도 PDF 업로드는 텍스트/글꼴/좌표 처리·문항 분리·캡처·수식 복원·성취기준 후보 추천·검토 경고 계산까지만 로컬에서 실행합니다. 화면의 API 연결 정보 조회는 로컬 상태 읽기이며 공급자 모델 호출이 아닙니다.
- **이 문항만 API로 판독**을 누르고 번호·공급자·캡처/추출문 전송·비용을 확인해야 AI에 요청합니다. 연결된 공통 지문이 포함될 수 있습니다. 취소·캡처 없음·중복 클릭·다른 작업 중에는 요청하지 않으며, API 대기 중 편집한 내용이나 다른 문항을 늦은 응답으로 덮어쓰지 않습니다. 키 저장 방식은 바꾸지 않았습니다.
- 전체 회귀 테스트 **220/220 통과**, 실패·생략 0. 실제 통합과학 PDF를 세 선택적 검사에도 지정했습니다. 로컬 분석 7개와 실제 UI 핸들러의 수동 판독 10개 검사, 기존 문서·수식·표·서식·문제함·공급자 모의 검사를 포함합니다.
- 압축 해제한 실행본을 격리된 Chromium에서 열어 통합과학 **25문항**, 긴 지문의 국어 **45문항**을 업로드했습니다. API 연결을 사용 가능으로 모의 처리했지만 두 업로드의 판독 POST는 각각 **0회**였습니다. 확인창 취소 0회, 두 번의 명시적 실행은 각각 선택 문항 1개만 요청했습니다. 두 번째 요청 중 편집 보호·키 미연결 차단·다른 문항 보존·버튼 재활성화도 통과했습니다. 외부 네트워크 요청·브라우저 콘솔/실행 오류는 0건이며 실제 유료 API는 사용하지 않았습니다.
- 데스크톱/모바일 화면을 확인했고 늘어난 API 안내가 사이드바 밖으로 넘치지 않도록 데스크톱 스크롤을 적용했습니다. TypeScript·`git diff --check` 통과. 기본 lint에는 기존 React compiler 1건·접근성 4건·Next 이미지 규칙 4건이 남습니다. 이전 소스와 대조했으며 해당 6개 규칙을 제외한 변경 파일 lint는 통과했습니다. 규칙 설정을 영구적으로 끄지는 않았습니다.
- 로컬 ZIP의 **95개 항목** CRC·UTF-8 이름·Mac 실행 권한 `0755`·배포 화이트리스트·개인 파일 제외·0.7.9 버전·현재 번들 일치를 검사했습니다. 이전 0.7.8 로컬 폴더/ZIP과 개인 원본 PDF·키·문제함은 보존했습니다. 브라우저 회귀 스크립트는 `tests/local-first-browser.cjs`에 있으며 개인 PDF와 스크린샷은 저장소/ZIP에 포함하지 않습니다.

이번 검사는 **자동 과금 경로 제거와 선택 문항 실행 흐름**을 확인한 결과입니다. 70문항의 의미·수식·매핑 정확도를 전수 승인한 것이 아닙니다. 순수 스캔 이미지의 무API OCR, 모든 PDF 수식 복원, 기존 매핑 검토 이슈는 해결되었다고 주장하지 않습니다. Windows 실기기·실제 공급자 유료 호출은 새로 검사하지 않았습니다.

## 0.7.8 — HWPX 네이티브 수식·원문 밑줄·음수 지수

- HWPX 본문·상자·표 셀의 지원 수식을 한글 편집 수식 객체로 내보냅니다. 분수·근호·첨자·화학식 전하·극한·합·행렬·구간별 함수를 구조로 변환합니다. 미지원 명령·서식이나 잘못된 수식은 문항 번호와 함께 내보내기를 중단합니다. 임의의 모든 LaTeX를 지원한다는 뜻은 아닙니다.
- PDF 밑줄의 글자 기준선 허용 범위를 보완했습니다. 원문과 정확히 대응하는 구절은 AI 재판독 뒤에도 굵게·밑줄을 보존하며, 바뀐 내용·모호한 반복 구절에 서식을 추측해서 옮기지는 않습니다. 통합과학 13번의 두 밑줄과 18번의 줄바꿈 밑줄을 원본 좌표로 다시 추출하고 저장된 텍스트에 대응시켜 확인했습니다.
- 부호와 숫자가 같은 작은 글자 기준선에 있는 지수를 묶고 중복 첨자 연결을 방지했습니다. 실제 PDF 17번의 두 수치가 `10^{−27}`로 복원됩니다. 중첩 지수·동위원소·이온 전하·이웃 셀을 함께 회귀 검사했습니다.
- DOCX에는 곧은 화학식·단위 글꼴과 수식 전체 밑줄을 명시합니다. 합 기호 뒤 일반 괄호로 감싼 피연산식이 비어 있는 수식 칸으로 표시되던 뷰어 호환 문제도 보완했습니다.
- 전체 회귀 테스트 **207/207 통과**, 실패·생략 0. 실제 PDF를 세 선택적 검사에 모두 지정했습니다. TypeScript·변경 파일 lint·`git diff --check` 통과. 외부 AI API 호출은 0회입니다.
- 통합과학 25문항 HWPX를 생성하고 핵심 13·17·18번 및 합성 수식 문서를 대조했습니다. 5개 HWPX의 업스트림 네임스페이스·마무리·구조·엄격 검사를 실행했습니다. 레이아웃 검사의 발문 들여쓰기 경고와 셀 내부 검사 범위 한계는 유지하며 실제 표 높이 검증과 구분합니다.
- macOS 한컴오피스 한글 12.30에서 합성 수식 문서와 실제 13·17번 HWPX를 열었습니다. 화학식·전하·분수·중첩 지수·극한·합과 13번의 두 밑줄, 17번 표 안 음수 지수가 표시되는 것을 확인했습니다. 25문항 전체의 한컴 페이지별 시각 검증을 완료한 것은 아닙니다.
- DOCX 대조 파일 4개를 번들 LibreOffice로 **총 6쪽** 렌더링하고 전쪽을 확인했습니다. 화학식/단위의 곧은 글꼴, 수식 전체 밑줄, 합의 피연산식, 17번 지수는 정상이며 글자 잘림·표 겹침은 발견하지 못했습니다. 17번 발문 끝이 다음 쪽으로 넘어가는 기존 쪽 나눔은 남아 있습니다. Windows·Word 실기기에서 이번 패치를 새로 검증하지는 않았습니다.
- 로컬 배포 ZIP **95개 항목**의 CRC·UTF-8 파일명·Mac 실행 권한 `0755`·필수 파일·개인 자료 제외·0.7.8 버전·수정 번들을 검사했습니다. 별도 임시 폴더에 압축을 풀어 첫 화면·PDF worker MIME·임시 문제함 저장/재시작·다른 출처/Host 차단 검사도 통과했습니다. 이전 로컬 배포 폴더와 ZIP은 백업하고 원본 개인 자료는 포함하지 않았습니다.

예전 검토 JSON에 빠진 밑줄은 원본 PDF를 다시 분석하거나 직접 수정해야 합니다. 검토 파일만 열어서는 원본의 선·글자 좌표를 복원할 수 없습니다. 이미 틀린 수식 의미·표 값과 과거 전수 검증의 미해결 매핑/누락 이슈를 모두 해결했다는 결과가 아닙니다. 원본 PDF·JSON·DOCX·키·기존 문제함은 보존하고 개인 대조 자료는 GitHub와 ZIP에서 제외합니다.

## 0.7.7 — DOCX 네이티브 수식·화학식·분할 표

- 본문·상자·표 셀의 지원되는 수식을 Word 편집 수식(OMML)으로 변환합니다. 잘못된 수식이나 미지원 구조는 문항 번호가 있는 오류로 내보내기를 중단합니다. 원시 LaTeX를 조용히 남기거나 일부를 버리지 않습니다. HWPX의 네이티브 수식 변환은 이번 범위가 아닙니다.
- 화학 문맥의 확인된 분자·이온식은 곧은 원소 기호로 표시하고 첨자·전하를 유지합니다. 수학·물리 변수, 유전자 표기, 모호한 영문은 임의로 바꾸지 않습니다. 일반 목록 앞 리터럴 `\n`은 실제 줄바꿈으로 정리하고 정상 LaTeX·코드·인용 문자열은 보존합니다.
- 표 일부 열만 가로지르는 가로선을 자식 행 경계로 사용합니다. 부모 제목은 자식 행에 반복하며 실제 병합 셀 자체를 재현하지는 않습니다. AI 변환 전후 같은 표에서 수치가 빠지거나 셀이 비어지면 기존 결과를 보존하도록 검사를 강화했습니다.
- 제출된 통합과학 PDF·25문항 검토 JSON·DOCX를 대조했습니다. 원본 PDF의 두 용액 행에서 각각 네 값이 올바른 열에 남는 것을 재추출로 확인했습니다. 기존 JSON에서 이미 빠진 값은 자동 복구 대상이 아니므로, 원본 대조 수정 JSON은 별도 개인 파일로 제공합니다.
- 회귀 테스트 **180/180 통과**, 실패·생략 0. 실제 PDF를 두 선택적 검사에 모두 지정했습니다. TypeScript·변경 파일 lint·웹/로컬 renderer 빌드 및 `git diff --check` 통과. 캡처 캡션의 페이지 연결 수정 후 문서 관련 46개·TypeScript·renderer 빌드도 재통과했습니다.
- 수정 JSON 25문항을 다시 가져와 전체 DOCX 생성이 완료되는 것을 검사했습니다. 핵심 5문항 대조 DOCX는 **수식 객체 20개, 원문 캡처 5장**, 일반 텍스트의 수식 구분자 `$`·리터럴 `\n` 0건, ZIP CRC·XML 구문 검사 통과입니다. 이는 25문항 전체의 의미 정확도 승인이 아닙니다.
- 대조 DOCX를 11쪽 이미지로 렌더링해 전쪽을 확인했고, 실제 macOS Microsoft Word에서 곧은 화학식, 첨자 수식, 분할 표, 한국어 분수의 표시를 확인했습니다. 번들 LibreOffice 렌더러에서는 OMML 글꼴·한국어 분수 간격 차이가 관찰되므로 Word 결과와 구분합니다. 한컴·Windows 실기기는 확인하지 않았습니다.
- 0.7.7 로컬 ZIP의 95개 항목 CRC·UTF-8 이름·Mac 실행 권한 `0755`·필수 파일·금지 개인 파일 제외·버전·수정 번들을 검사했습니다. 별도 압축 해제본의 첫 화면·PDF worker·임시 문제함 저장/재시작·외부 출처 차단 검사도 통과했습니다. 기존 로컬 배포 ZIP 7개는 바꾸지 않았습니다.
- API 호출 0회. 원본 시험지·원본 JSON/DOCX·키·기존 문제함은 수정하지 않았습니다. 개인 수정본과 상세 대조 로그는 저장소·배포 ZIP에서 제외합니다.

남은 한계: 이미 누락된 분자·부호·표의 값은 원본 확인이 필요합니다. 원본 대조 과정에서 발견한 지수/분자 손상은 개인 수정본에서 고쳤지만, 문항 번호별 정답을 앱에 하드코딩하지 않았습니다. 성취기준 선택은 이번에 재평가하지 않았습니다. 새 표 추출은 **원본 PDF 재선택**에 적용되며 옛 검토 파일을 열기만 해서 빠진 행이 복원되지는 않습니다.

## 0.7.6 — 캡처 이미지 전용 ZIP

- PDF 결과·문제함의 공통 내보내기에 캡처 이미지 ZIP을 추가합니다. `questionCaptures`만 원래 순서·바이트 그대로 보존하며 전체 페이지 대체·선택지 추가·중복 제거·이미지 재인코딩을 하지 않습니다.
- 제출된 수학 검토 파일 30문항의 31개 캡처(여러 장 문항 1개)를 재가져와 ZIP으로 내보냈습니다. 31장 모두 기존 캡처 바이트와 일치하고 입력 파일은 변경하지 않았습니다. 결과 ZIP은 개인 작업 폴더에만 두며 배포하지 않습니다.
- 새 회귀 사례는 여러 PDF의 같은 이름·문항 번호, 같은 페이지의 여러 영역, 여러 페이지, 반복 이미지, JPG/PNG, 한글/Windows 파일명, 누락·외부 URL·손상된 데이터 거절, 용량 제한, 다운로드 URL 해제와 이미지 외 필드 제외를 검사합니다.
- 회귀 테스트 **140개**, TypeScript 및 웹/로컬 renderer 빌드를 통과했습니다. 31장 이미지 ZIP의 CRC·실제 이미지 디코딩·UTF-8 이름을 검사했습니다. 내보내기 대화상자 연결은 소스 검사, 파일 다운로드는 DOM/URL 대체 객체를 사용한 검사입니다.
- 0.7.6 배포 ZIP의 95개 항목 CRC·UTF-8 이름·Mac 실행 권한·필수 파일·개인 자료 제외·번들 버전/새 기능을 검사했습니다. 실제 압축 해제본의 첫 화면·PDF worker MIME·임시 문제함 저장/재시작·다른 출처 차단 검사를 통과했습니다.
- API 호출은 0회이며 원문 캡처 범위나 텍스트·성취기준의 의미 정확성을 새로 판정한 검사는 아닙니다. 실제 브라우저 조작·Windows 실기기 검사는 수행하지 않았습니다.

## 0.7.5 — 중앙 목록 구조 표시
