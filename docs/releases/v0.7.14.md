# 문항맵 0.7.14 — 버전 확인·문제함 문항 수정

0.7.11 공개판 이후의 0.7.12·0.7.13 로컬 검증 변경을 함께 포함하는 정식 로컬 실행본입니다. 아래 첨부된 `munhang-map-local-0.7.14.zip`을 사용하세요. GitHub의 자동 생성 `Source code` ZIP은 실행용이 아닙니다.

- **0.7.12 포함:** 캡처 이미지를 현재 성취기준별 폴더와 문항목록 CSV로 내보냅니다. 여러 PDF의 같은 번호와 미분류 문항도 보존하며 재매핑·API 호출을 하지 않습니다.
- **0.7.13 포함:** 과학탐구 대조에서 확인한 글리프·분수·첨자·벡터·밑줄·표·상자·읽기 순서와 일부 추천 후보 오류를 보정합니다. 일반 변수의 오른쪽 첨자를 핵종의 왼쪽 첨자로 바꾸는 API 응답도 검사합니다.

- 상단 **버전 확인** 버튼에서 실행 버전과 GitHub 정식 로컬 릴리스를 비교합니다. 새 실행 ZIP이 준비되어 있으면 다운로드 링크를 제공합니다. 로컬 수정본이 공개판보다 새로우면 다운그레이드를 권하지 않습니다.
- 확인은 버튼을 누를 때만 실행하며 1분간 같은 결과를 사용합니다. 인터넷 장애·요청 제한·릴리스 또는 ZIP 준비 중을 구분합니다. 고정된 공개 GitHub 주소만 사용하고 시험지·문항·API 키를 보내지 않습니다.
- **내 문제함 → 문항 수정**으로 기존 문항의 LaTeX·본문·상자·표·굵게·밑줄을 고칠 수 있습니다. 잘못된 수식이 저장된 문항도 편집창에서 열립니다.
- **수식 검사**, 수정 미리보기, **수정 저장**을 제공합니다. 저장 후 내보내기는 최신 저장 내용을 사용합니다. 캡처·성취기준·같은 PDF의 다른 문항을 유지하며 API를 호출하지 않습니다.
- 새 저장·수정 저장 전에 화면·DOCX·HWPX 수식 변환을 검사하고, 실패하면 문항 번호와 원인을 안내해 저장을 막습니다. 수식의 의미·정답 정확도를 보증하는 검사는 아닙니다.
- 저장 실패 시 초안을 유지하고, 미저장 내용을 닫거나 다른 문항으로 이동할 때 확인합니다. 다른 창의 선행 수정과 충돌하면 덮어쓰지 않습니다. 저장/취소하기 전에는 내보내기를 막습니다.

## 업데이트 방법

Node.js **22.13 이상 LTS**를 설치하세요. 검토 결과를 저장하고 이전 서버를 종료한 뒤 새 ZIP을 **별도 폴더**에 풀어 Mac은 `문항맵.command`, Windows는 `문항맵.bat`를 실행합니다. 자동 설치나 실행 중 파일 덮어쓰기는 하지 않습니다. 같은 컴퓨터의 사용자 데이터 폴더를 유지하면 문제함·연결 설정도 유지됩니다. 강제 종료 후 저장 잠금이 계속 남는 경우의 복구 방법은 [사용법](https://github.com/RuneDaeg/munhang-map/blob/main/README.md#6-검토-저장과-내-문제함)을 참고하세요.

검증 범위와 미확인 사항은 [현재 검증 상태](https://github.com/RuneDaeg/munhang-map/blob/main/docs/VALIDATION_STATUS.md)에 기록합니다. 수식·매핑은 초안이므로 원문과 대조해야 합니다.
