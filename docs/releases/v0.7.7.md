## 문항맵 0.7.7 — Word 수식·화학식·표 세부 행 보완

### 변경 사항

- DOCX 본문·자료 상자·표 셀의 지원되는 수식을 Word에서 수정 가능한 **네이티브 수식(OMML)** 으로 내보냅니다. 분수·근호·첨자·극한·합·행렬 등의 구조를 보존합니다.
- 화학 문맥에서 분자식·이온식의 원소 기호를 곧게 표시하고 아래첨자·전하를 유지합니다. 수학·물리 변수와 유전자 표기를 무조건 화학식으로 바꾸지 않습니다.
- 일반 목록 앞에 문자로 남은 `\n`을 실제 줄바꿈으로 정리합니다. 정상 수식 명령과 배열의 행 구분, 코드·인용 문자열은 보존합니다.
- 일부 열에만 그어진 가로선도 표의 세부 행 경계로 읽습니다. 세로 병합된 부모 제목은 각 자식 행에 반복하고 수치의 행·열 대응을 보존합니다.
- AI 결과에서 표의 기존 숫자가 빠지거나 셀이 비어지면 기존 결과를 지키도록 검사를 보강했습니다. 원문 캡처 캡션이 이미지와 다른 페이지에 홀로 남지 않게 연결합니다.

변환 불가능한 명령·잘못된 수식·수식 내부의 부분 서식은 **문항 번호를 안내하고 DOCX 내보내기를 중단**합니다. 해당 문항을 고친 뒤 다시 내보내세요. 임의의 모든 LaTeX 명령 지원은 아닙니다. HWPX는 계속 LaTeX 원문과 캡처를 보존하며, 실제 병합 셀 모양이나 그림 배치까지 원본과 똑같이 재현하지는 않습니다.

### 업데이트 방법

1. 아래 **munhang-map-local-0.7.7.zip**을 받습니다. `Source code (zip)`은 실행용 배포본이 아닙니다.
2. 기존 결과를 **검토 저장**하고 옛 서버를 종료합니다. 새 ZIP을 **새 폴더에 전부 압축 해제**하세요.
3. Node.js **22.13 이상인 지원 중 LTS**를 설치하고 Mac은 `문항맵.command`, Windows는 `문항맵.bat`를 실행합니다. 터미널 창은 사용하는 동안 열어 둡니다.
4. 화면 상단 **v0.7.7**을 확인합니다. 기존 결과를 **검토 파일 열기**로 불러온 뒤 DOCX로 다시 내보내면 네이티브 수식 변환이 적용됩니다.
5. **이미 표의 값이 빠진 파일은 원본 PDF를 다시 넣거나 원본 대조 수정본을 가져와야 합니다.** 옛 검토 파일을 여는 것만으로 없어진 값·수식 의미가 복구되지는 않습니다.

Mac 보안 안내가 나오면 우클릭 → 열기를 이용하세요. ZIP 내부나 HTML 하나만 직접 열지 마세요. 개인 문제함과 API 설정은 별도 데이터 폴더에 유지됩니다. 이전 릴리스는 보존합니다.

### 검증과 제한

- 회귀 테스트 **180개 전부 통과**, TypeScript·변경 파일 lint·웹/로컬 빌드 통과. 실제 PDF 검사도 실행했습니다.
- 제출된 과학 자료의 표 세부 행·수치 보존을 재추출로 확인했습니다. 별도 개인 대조 DOCX의 수식 객체 20개·원문 캡처 5장·XML·CRC를 검사하고 11쪽을 렌더링했습니다.
- 실제 macOS Microsoft Word에서 화학식의 곧은 글꼴, 첨자, 분할 표와 한국어 분수를 확인했습니다. LibreOffice에서는 일부 수식의 글꼴·간격이 Word와 다를 수 있습니다. Windows 실기기·한컴·유료 AI API 검사는 포함하지 않습니다.
- 로컬 ZIP 95개 항목의 CRC·UTF-8 파일명·Mac 실행 권한·필수 파일·개인 자료 제외를 검사했습니다. 실제 압축 해제본의 첫 화면·PDF worker·임시 문제함 저장/재시작·다른 출처 차단도 통과했습니다.
- 모든 문항의 수식 의미·성취기준 정확도를 승인한 결과는 아닙니다. 원본 시험지·검토 JSON·개인 문제함·API 키는 배포하지 않습니다.
