## 문항맵 0.7.4 — AI 수식 이스케이프 복원·오류 검토

### 주요 수정

- `\bigg`·`\bar`가 백스페이스 문자로, `\to` 등이 탭으로 바뀌던 AI JSON 수식 복원.
- `lim` 조건을 연산자 아래에 표시. 수식 시작 줄바꿈·중복 역슬래시 보완.
- KaTeX 문법 오류, 수식 구분자·분리된 첨자·절댓값, 긴 발문 전체 중복을 경고로 표시.
- 잘못된 AI 수식은 정상 기존 추출문을 덮어쓰지 않으며 공통 지문의 개별 발문도 검사.

### 실행·업데이트

1. **munhang-map-local-0.7.4.zip**을 받습니다. `Source code (zip)`은 바로 실행하는 배포본이 아닙니다.
2. 기존 결과를 **검토 저장**하고 옛 서버를 종료한 뒤, 새 ZIP을 **별도 폴더에 전부 압축 해제**합니다.
3. Node.js **22.13 이상인 지원 중 LTS**를 설치하고 Mac은 `문항맵.command`, Windows는 `문항맵.bat`를 실행합니다. 사용 중에는 터미널 창을 유지합니다.
4. 앱 상단 **v0.7.4**를 확인하고 **검토 파일 열기**로 저장 파일을 불러옵니다. 알려진 이스케이프 손상은 이때 복원되며 API 재호출은 필요 없습니다.

Mac에서 확인할 수 없는 개발자 안내가 나오면 우클릭 → 열기를 사용하세요. HTML 파일만 직접 열지 마세요. 이전 릴리스는 그대로 보존합니다. 기존 문제함·API 설정은 별도 데이터 폴더에 유지됩니다.

### 검증과 한계

회귀 테스트 **130개 통과**, TypeScript·웹/로컬 빌드 통과. 제출된 수학 검토 JSON 30문항의 별도 수정본으로 저장·재가져오기 및 60회 목록/상세 렌더링을 검사했습니다. 원본 JSON·페이지 이미지·캡처 좌표·성취기준 코드는 보존했습니다. 실제 AI API 호출은 하지 않았습니다.

개별 원문 대조로 고친 의미 오류를 앱의 임의 자동 추정 규칙으로 넣지 않았습니다. 따라서 누락된 절댓값이나 틀린 수식은 원문을 보며 수정해야 하며, **경고 없음은 의미·매핑 정확성 보장이 아닙니다.** 그림 라벨 혼입과 일부 캡처 범위도 남습니다. Windows 실기기·Word/한컴 실행 검증은 포함하지 않습니다.

시험지·검토 JSON·상세 개인 로그·API 키·문제함은 배포하지 않습니다. AI 판독을 사용하면 선택한 공급자에게 문항 이미지와 텍스트가 전송되며 비용이 발생할 수 있습니다.
