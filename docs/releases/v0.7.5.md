## 문항맵 0.7.5 — 중앙 문항 목록에도 박스·표 표시

### 변경 사항

- 중앙 목록에서도 오른쪽과 같은 자료·보기 박스와 표를 표시합니다.
- 굵게·밑줄·수식과 중첩된 박스·표를 유지합니다.
- 긴 문항을 두 줄로 자르지 않으며 넓은 표·수식은 가로로 스크롤할 수 있습니다.
- 문항 선택 버튼과 미리보기를 분리하고 키보드 접근을 지원합니다.
- 0.7.4의 AI 수식 이스케이프 복원과 검토 경고 개선도 포함합니다.

### 다운로드·업데이트

1. **munhang-map-local-0.7.5.zip**을 내려받습니다. `Source code (zip)`은 바로 실행하는 배포본이 아닙니다.
2. 기존 결과를 **검토 저장**하고 옛 서버를 종료한 뒤 새 ZIP을 **별도 폴더에 전부 압축 해제**합니다.
3. Node.js **22.13 이상인 지원 중 LTS**를 설치하고, Mac은 `문항맵.command`, Windows는 `문항맵.bat`를 실행합니다. 사용하는 동안 터미널 창을 열어 두세요.
4. 상단 **v0.7.5**를 확인하고 **검토 파일 열기**로 기존 결과를 불러옵니다. 표시 방식 변경이므로 PDF·API 재판독은 필요 없습니다.

Mac에서 확인할 수 없는 개발자 안내가 나오면 우클릭 → 열기를 사용하세요. ZIP 내부나 HTML 파일만 직접 실행하지 마세요. 기존 문제함·API 설정은 별도 데이터 폴더에 유지됩니다. 이전 릴리스는 그대로 보존하며, 앞으로 ZIP 변경 시 GitHub 릴리스도 함께 갱신합니다.

### 검증 범위

회귀 테스트 **131개**, TypeScript·웹/로컬 빌드를 통과했습니다. 수학 30문항의 중앙/상세 구조 수가 일치하고 18번의 두 박스가 모두 렌더링됩니다. 60회 렌더링에서 KaTeX 오류가 없었습니다. ZIP의 CRC·필수 파일·개인 자료 제외·한글 이름·Mac 실행 권한과 압축 해제본의 로컬 서버 동작을 검사했습니다.

실제 브라우저에서의 마우스·터치·화면 크기 변경, Windows 실기기 및 Word/한컴 실행 검사는 포함하지 않습니다. 표시 정상화가 수식 의미·성취기준 정확성을 보장하지는 않습니다.

시험지·개인 검토 JSON·API 키·문제함은 배포하지 않습니다. API 재판독을 별도로 실행하면 선택한 공급자에게 문항 이미지·텍스트가 전송되고 비용이 발생할 수 있습니다.
