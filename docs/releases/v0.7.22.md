# v0.7.22 | 작업 보존과 문항 검토 화면 개선

- API 설정을 별도 창에서 열고 원래 작업 화면에서 연결 상태를 갱신합니다. 새 시험지 분석이 실패해도 이전 작업을 이어갈 수 있습니다.
- PDF 문항 분할 시 내부 번호 충돌을 방지해 정답 연결과 검토 JSON 저장·복원을 보호합니다.
- 판독 중 수정한 정답을 보존하고, 본문이 충돌하면 교사가 수정본과 API 응답을 비교해 선택할 수 있습니다.
- 좁은 화면에서는 선택한 문항 바로 아래에 편집창을 엽니다. ‘확인 필요만 보기’와 ‘다음 확인 문항’은 원본 번호를 유지합니다.
- 예시 화면의 주요 동작을 ‘내 시험지 불러오기’로 바꾸고, 실제 작업에 맞춰 단계와 도움말을 표시합니다.
