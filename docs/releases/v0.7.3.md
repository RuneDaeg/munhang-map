## 문항맵 0.7.3 — 수학·국어 추출 개선

이 ZIP에는 최신 수학·국어 수정이 포함되어 있습니다. 이전 0.7.2는 복구용으로 보존합니다.

### 다운로드하고 실행

1. 아래 **munhang-map-local-0.7.3.zip**을 내려받아 **전체 압축을 풉니다**. `Source code (zip)`은 바로 실행하는 배포본이 아닙니다.
2. [Node.js](https://nodejs.org) **22.13 이상인 지원 중 LTS**를 설치합니다. Git·pnpm 설치는 필요하지 않습니다.
3. Mac은 `문항맵.command`, Windows는 `문항맵.bat`를 실행합니다. 사용하는 동안 터미널 창을 열어 두세요.
4. 앱 상단의 **v0.7.3**을 확인하고 원본 PDF를 다시 선택합니다.

Mac에서 확인할 수 없는 개발자 안내가 나오면 파일을 우클릭 → 열기로 실행하세요. 폴더 전체를 함께 보관하고, ZIP 내부나 `renderer/index.html`을 직접 실행하지 마세요.

### 기존 사용자 업데이트

수동 수정본을 먼저 **검토 저장** → 이전 서버 종료 → 새 ZIP을 별도 폴더에 압축 해제 → 새 실행 파일을 엽니다. 기존 문제함·API 설정은 별도 데이터 폴더에 유지됩니다. 저장된 문항은 자동 재분석되지 않으므로 새 알고리즘을 적용하려면 PDF를 다시 넣으세요.

### 주요 변경

- 중첩 지수·분수, 극한·합 첨자, 근호, 선분 윗줄, 구간별 함수 및 화학식 괄호 아래첨자 복원.
- 국어 공통 지문 연결, 병합 표 제목·메모·작은 상자, [A]/[B] 범위와 원문 굵게·밑줄 보존.
- 문항별 평가 요소·교과로 성취기준 후보 제한. 추천 퍼센트를 검토 사유로 교체.
- 수동 분리 문항의 발문 보존, 교과 변경 시 이전 추천 근거 제거, 정규분포 영역 분류 보정.
- 통합과학 표 안 반응식 누락, 영어 화살표 및 달러 금액 표시 보정.

### 검증 범위와 한계

외부 AI API 호출 없이 8개 PDF·225문항을 재검사했고 회귀 테스트 125개가 통과했습니다. 수학 수식 134개의 KaTeX 문법과 국어 공통 지문 11세트 연결을 확인했습니다. 배포 ZIP은 필수 파일·개인 자료 제외·CRC·UTF-8 이름·Mac 실행 권한을 검사합니다.

이 결과는 의미 정확도·성취기준 정답률이 아닙니다. 그림 내부 선택지·미지원 글꼴·순수 스캔 OCR과 일부 수식은 원문 대조가 필요합니다. DOCX/HWPX 수식은 LaTeX 원문과 캡처로 보존되며 네이티브 수식 객체가 아닙니다. Windows 실기기와 Word/한컴 실행은 이번에 검증하지 못했습니다.

API 키 없이도 기본 문항 분리·캡처·후보 추천·문서 내보내기가 가능합니다. AI 판독을 사용하면 선택한 공급자에게 문항 이미지와 텍스트가 전송되고 비용이 발생할 수 있습니다. 시험지·캡처·키·개인 문제함은 배포본에 포함하지 않습니다.

자세한 내용은 [검증 보고서](https://github.com/RuneDaeg/munhang-map/blob/v0.7.3/docs/VALIDATION_STATUS.md)와 ZIP 안의 `사용법.txt`를 참고하세요.
