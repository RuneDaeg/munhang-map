## 문항맵 0.7.6 — 문항 캡처 이미지만 ZIP으로 받기

### 변경 사항

- **내보내기 → 캡처 이미지만 · ZIP**으로 현재 문항 전체 캡처를 JPG/PNG 파일로 받습니다. API 호출·재분석 없이 저장된 캡처의 화질을 유지합니다.
- **내 문제함**에서도 여러 PDF의 필요한 문항만 선택해 같은 기능을 사용할 수 있습니다.
- 문항 순번·PDF 이름·원래 문항 번호·캡처 순번·쪽수를 파일명에 남깁니다. 이름이나 번호가 같아도 덮어쓰지 않으며, 여러 장인 문항은 모두 별도 이미지로 보존합니다.
- 캡처가 없거나 손상된 문항은 안내하며 조용히 제외하지 않습니다. 처리 진행 상황과 캡처 범위 경고도 표시합니다.
- 이전 버전의 박스·표·수식 표시 및 수식 검토 개선도 포함합니다.

그림만 자동으로 다시 잘라내는 기능은 아닙니다. 필요한 범위는 먼저 **캡처 범위 수정**에서 조정하세요. 이미지 ZIP에는 문서·CSV·키를 넣지 않지만 이미지 자체의 개인정보는 지우지 않습니다. 내보내기는 1,000장/이미지 합계 150MB로 제한합니다.

### 다운로드·업데이트

1. 아래 **munhang-map-local-0.7.6.zip**을 받습니다. `Source code (zip)`은 바로 실행하는 배포본이 아닙니다.
2. 기존 결과를 **검토 저장**하고 옛 서버를 종료한 뒤 새 ZIP을 **별도 폴더에 전부 압축 해제**합니다.
3. Node.js **22.13 이상인 지원 중 LTS**를 설치하고, Mac은 `문항맵.command`, Windows는 `문항맵.bat`를 실행합니다. 사용하는 동안 터미널 창을 열어 두세요.
4. 상단 **v0.7.6**을 확인합니다. **검토 파일 열기** 또는 **내 문제함**에서 기존 캡처를 사용하면 됩니다. API 재판독은 필요 없습니다.

Mac에서 확인할 수 없는 개발자 안내가 나오면 우클릭 → 열기를 사용하세요. ZIP 내부나 HTML 파일만 직접 실행하지 마세요. 기존 문제함·API 설정은 별도 데이터 폴더에 유지됩니다. 이전 릴리스는 보존하며 ZIP 변경 시 GitHub 릴리스도 함께 갱신합니다.

### 검증 범위

제출된 수학 검토 파일 30문항의 캡처 **31장**이 모두 ZIP에 포함되고 기존 캡처 바이트와 일치함을 확인했습니다. 여러 조각·번호 중복·누락·잘못된 이미지·안전한 파일명·개인 데이터 제외·진행 상태를 회귀 검사합니다. API 호출 없이 검증하며 개인 시험지·검토 JSON·문제함은 배포하지 않습니다.

회귀 테스트 **140개**, TypeScript·웹/로컬 빌드를 통과했습니다. 31장의 이미지 디코딩과 ZIP CRC를 검사했고, 배포 ZIP의 UTF-8 이름·Mac 실행 권한·필수 파일·개인 자료 제외 및 압축 해제본의 로컬 서버 동작을 확인했습니다.

실제 브라우저 조작·Windows 실기기 검사는 포함하지 않습니다. 내보내기 검증은 원래 캡처 범위나 추출 텍스트·수식·성취기준의 정확성을 보장하지 않습니다.
