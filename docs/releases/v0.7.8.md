## 문항맵 0.7.8 — 한글 편집 수식·원문 밑줄·음수 지수 보완

### 변경 사항

- HWPX 본문·자료 상자·표 셀의 지원되는 수식을 한글에서 편집 가능한 **네이티브 수식 객체**로 내보냅니다. 분수·근호·위아래 첨자·화학식과 전하·합·극한·행렬·구간별 함수 등의 구조를 변환하고 원문 캡처도 첨부합니다. `0.7.7`의 HWPX LaTeX 원문 보존 방식은 이 버전에서 바뀌었습니다.
- DOCX와 HWPX 모두 미지원 명령·구조·글꼴이나 잘못된 수식이 있으면 **문항 번호를 안내하고 내보내기를 중단**합니다. 해당 문항을 수정한 뒤 다시 내보내세요. 임의의 모든 LaTeX 명령이나 수식 내부 부분 서식을 지원하는 것은 아닙니다.
- PDF 글자 기준선과 밑줄 사이의 거리를 보완하고 표 테두리·분수선을 구분합니다. AI 판독 후 원문과 정확히 대응하는 구절의 굵게·밑줄을 보존합니다. 바뀐 내용이나 대응이 모호한 반복 구절에는 서식을 추측해서 옮기지 않습니다.
- PDF에서 부호와 숫자가 같은 작은 글자 기준선에 놓인 지수를 하나로 연결합니다. `10^{−}^{27}`로 갈라지던 배치는 `10^{−27}`로 복원하며, 실제 중첩 지수·위아래 첨자·화학식 전하의 역할을 유지합니다.
- `0.7.7`의 DOCX 네이티브 수식·화학식 글꼴·표 세부 행·목록 줄바꿈 개선과 캡처 이미지 전용 ZIP 내보내기도 포함합니다.

### 업데이트 방법

1. **munhang-map-local-0.7.8.zip**을 받습니다. `Source code (zip)`은 실행용 배포본이 아닙니다.
2. 기존 수정본을 **검토 저장**하고 옛 서버를 종료합니다. 새 ZIP을 **새 폴더에 전부 압축 해제**하세요.
3. Node.js **22.13 이상인 지원 중 LTS**에서 Mac은 `문항맵.command`, Windows는 `문항맵.bat`를 실행하고 화면 상단 **v0.7.8**을 확인합니다.
4. 올바른 수식이 저장된 검토 파일은 다시 열고 HWPX로 내보내면 네이티브 수식으로 변환됩니다. 수식 변환·저장·내보내기는 외부 AI를 호출하지 않습니다.
5. **빠진 밑줄·잘못 분리된 지수·누락된 표 값은 원본 PDF를 다시 분석하거나 원문 대조로 수정해야 합니다.** 예전 검토 파일을 여는 것만으로 원본의 선·글자 좌표를 다시 읽거나 없어진 수식 의미를 복원하지는 않습니다. API 재판독을 선택하면 연결한 공급자의 비용이 발생할 수 있습니다.

저장소 공개 상태와 이전 릴리스는 유지합니다. 개인 문제함과 API 설정은 별도 데이터 폴더에 남습니다. 시험지·검토 JSON·개인 문제함·API 키는 배포 ZIP에 포함하지 않습니다.

### 검증과 제한

- 실제 원본 PDF에서 음수 지수 복원을 확인하고, HWPX 검증 파일의 구조·엄격 검사를 실행했습니다. 원본 파일을 변경하지 않은 채 별도 복사본에 업스트림 마무리 검사를 적용했으며 ZIP 내부 내용의 수정은 필요하지 않았습니다.
- 전체 회귀 테스트 **207개 통과**, 실패·생략 0. TypeScript·변경 파일 lint 검사도 통과했습니다. macOS 한글에서 수식 대조 문서와 실제 13·17번 HWPX의 수식·밑줄·음수 지수를 확인했습니다. DOCX 4개는 총 6쪽을 렌더링해 전쪽을 대조했습니다. 상세 결과와 한계는 [현재 검증 상태](https://github.com/RuneDaeg/munhang-map/blob/v0.7.8/docs/VALIDATION_STATUS.md)에 기록합니다. 유료 AI API 검사는 실행하지 않았습니다.
- 로컬 ZIP 95개 항목의 CRC·UTF-8 이름·Mac 실행 권한·필수 파일·개인 자료 제외·버전·수정 내용 검사와 실제 압축 해제본의 첫 화면·PDF worker·임시 문제함/재시작·출처 차단 검사를 통과했습니다.
- 구조 검사만으로 한컴 화면의 줄바꿈·표 높이·글꼴을 보장하지 않습니다. 업스트림 레이아웃 검사에는 번호가 있는 발문과 이어지는 본문을 들여쓰기 부족으로 보는 경고가 있으며, 셀 안 문단을 검사하는 범위에도 제한이 있습니다. 사용하는 Word·한글에서 원문과 대조해 주세요.
- 실제 병합 셀 모양이나 그림 배치까지 원본과 동일하게 재현하지는 않습니다. Windows 실기기 및 모든 문항의 수식 의미·성취기준 정확도를 승인한 결과는 아닙니다.

본 제품은 한글과컴퓨터의 한글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다. 자세한 출처는 배포본의 `THIRD_PARTY_NOTICES.md`에 있습니다.
