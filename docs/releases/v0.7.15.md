- 한국사 시험지의 말풍선·신문·초대장·기획안 등 불규칙한 자료틀을 텍스트 소속과 함께 감지합니다. 여러 조각으로 나뉜 자료 이미지를 연결하고, 나란히 놓인 해설·대사의 읽기 순서를 개선합니다.

- 자료의 실제 선·이미지 경계를 문항 캡처에 반영해 오른쪽 가장자리 잘림을 줄입니다. 다른 단과 페이지 번호는 포함하지 않도록 검사합니다.

- **인식 오류 제보**에서 오류 설명을 적고, 검토 JSON을 다운로드해 `rune_daeg@naver.com`으로 메일을 작성할 수 있습니다. JSON이 첨부된 `.eml` 초안 다운로드도 제공합니다.
- 제보 파일 생성은 로컬에서만 처리하며 자동 발송하지 않습니다. 메일 앱에 따라 `.eml` 초안 편집이 지원되지 않을 수 있으며, 이때는 JSON을 직접 첨부하세요. `mailto:` 링크는 첨부파일을 자동 추가하지 않습니다.
- 공유 권한 확인과 개인정보 안내를 제공합니다. **검토 JSON에는 원본 PDF의 모든 페이지 이미지와 문항·성취기준·수정 내용이 포함됩니다.** API 키·연결 설정은 제외됩니다. 반출 금지 문서·개인정보는 보내지 마세요.

## 업데이트와 검증 범위

아래 첨부된 `munhang-map-local-0.7.15.zip`이 실행용입니다. 기존 검토 결과를 저장하고 이전 서버를 종료한 뒤 새 ZIP을 별도 폴더에 풀어 실행하세요. Node.js 22.13 이상이 필요합니다. 기존 문제함·연결 설정은 유지됩니다.
