# 문항맵 0.7.16 — 수학 첨자·복합 수식·선택과목 분리

- PDF에 따로 배치된 음수·분수 지수를 하나의 위첨자로 복원합니다. `lim`, 합 기호, 적분의 위·아래 범위와 수열 아랫첨자를 실제 좌표로 연결합니다.
- 큰 괄호의 지수, 지수 안 분수·근호·함수, 세제곱근, 구간별 함수의 한국어/절댓값 조건을 보존합니다. 평균 윗줄·선분·벡터·미분 기호의 결합도 보완합니다.
- 검증한 글리프 윤곽 6종으로 미복원 수학 문자를 복원합니다. PDF.js가 합친 구조 기호는 실제 글리프 위치가 일치할 때만 분리하며, 알 수 없는 문자는 임의 치환하지 않습니다.
- 여러 선택과목이 들어 있는 시험지의 반복되는 23~30번을 별도 문항으로 분리합니다. 원본 번호·선택과목명은 화면, 검토 JSON, 내 문제함, DOCX/HWPX, 캡처 파일과 매핑 목록에 유지합니다.
- API 응답에서 기존의 유효한 지수·아래첨자·연산자 범위가 빠지면 기존 내용을 보존하고 경고합니다. 첨자 값의 교정과 기존 핵종 첨자 교정은 허용합니다.
- 집합 조건·조건부확률·구간별 함수의 세로줄 때문에 HWPX 내보내기가 중단되던 문자 변환도 보완합니다.

## 업데이트 방법과 한계

`munhang-map-local-0.7.16.zip`을 별도 폴더에 풀고 이전 실행 창을 종료한 뒤 실행하세요. Node.js 22.13 이상이 필요합니다. 기존 문제함·설정과 이전 릴리스는 보존합니다.

**원본 PDF를 다시 넣어야 새 좌표 분석이 적용됩니다.** 예전 검토 JSON에 이미 빠진 수식이나 합쳐진 선택과목은 텍스트만으로 추측해 복원하지 않습니다. 수정한 검토본을 먼저 보관하고 새 결과와 대조하세요.

최초 PDF 분석은 API 없이 로컬에서 처리됩니다. 유료 공급자 재판독 정확도, 성취기준 정답률, 모든 스캔·글꼴 지원을 보증하는 업데이트는 아닙니다. 그림은 원문 캡처로 보존하며, 자동 경고가 없어도 원문 확인이 필요합니다. 검증 범위는 [현재 검증 상태](https://github.com/RuneDaeg/munhang-map/blob/main/docs/VALIDATION_STATUS.md)를 참고하세요.
