# 문항맵 0.7.18 — HWPX 도서 호환·수식·보기 상자 개선

- `#강`과 `#구분` 형식, `유형 익히기` 같은 비숫자 문항 라벨을 함께 지원합니다. 원본의 `$$`·`@@` 메타데이터와 고유 문항 코드를 보존하며, 정답 연결·검토 JSON·문제함·CSV에서도 원본 식별자를 유지합니다.
- 투명 셀로 구성된 `<보기>` 제목·본문을 하나의 상자로 정리합니다. 화면과 DOCX/HWPX에 한 칸짜리 보기 표로 제공하고 실제 데이터 표나 중첩 표는 임의로 합치지 않습니다.
- 한글 수식의 핵종 왼쪽 첨자가 앞의 덧셈 기호에 붙는 문제, 각도 빈 기준 문자·삼각형의 문서 변환 문제, 여러 글자 로마체 화학식 변환을 보완합니다. 불확실한 수식은 원본 스크립트로 보존합니다.
- 큰 교재를 읽을 수 있도록 XML 항목 제한을 24 MiB로 조정합니다. 전체 용량·압축률·노드 수·중첩 깊이 등 나머지 안전 제한은 유지합니다.
- 새 문제함 저장 전에 해설도 수식 검사합니다. 원문 보존 수식의 개행과 역슬래시 때문에 생기던 저장 오탐·수식 경계 손상을 수정했습니다.

## 재검증

- 과학탐구 8권 2,621문항의 추출·정답 재연결·검토 JSON·문제함 저장/새 프로세스 재조회 통과.
- 보기 2,287개를 단일 상자로 확인. 수식 34,198개 중 31,177개 변환, 3,021개는 원문 보존 및 검토 대상으로 유지.
- 자동 회귀 472개 통과·실패 0개. 별도 PDF 입력을 요구하는 선택 검사 15개는 생략.
- 대표 DOCX·브라우저 표시 확인. HWPX 단일 표/수식 구조는 검사했으나 이번 한글 앱 화면 접근 오류로 한컴 실제 표시는 미확인입니다. 모든 문항의 의미·매핑 정확도를 인증한 결과는 아닙니다.

## 사용과 한계

이전 서버를 종료하고 새 ZIP을 별도 폴더에 풀어 실행하세요. Node.js 22.13 이상이 필요합니다. 기존 문제함·설정은 보존합니다.

**이미 만들어 둔 검토 JSON의 잘못된 수식·표를 일괄 수정하지는 않습니다.** 수동 수정본을 백업한 뒤 HWPX 원본을 다시 가져오면 새 변환을 적용합니다. 새로 생성한 문항을 문제함에 넣기 전 원본과 확인하세요.

HWPX 가져오기·정답 연결·문서 변환은 API 없이 로컬에서 처리합니다. 구형 HWP는 사용자가 한글에서 HWPX로 변환해야 합니다. 원본 페이지 캡처·병합 셀 배치·모든 수식 의미·성취기준 정확성을 보장하지 않습니다. 자세한 검증 범위와 남은 제한은 [검증 상태](../VALIDATION_STATUS.md)를 참고하세요.

원본 교재·정답·해설·생성 JSON·개인 문제함은 공개 저장소와 배포 ZIP에 포함하지 않습니다.
