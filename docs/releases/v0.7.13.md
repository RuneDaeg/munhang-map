# 문항맵 0.7.13 — 과학탐구 대조 오류 보정

0.7.13은 로컬 구현·검증 버전이며 별도 공개 ZIP 없이 [0.7.14](./v0.7.14.md)에 포함해 배포합니다.

- 검증된 내장 글자 모양으로 미복원 기호·변수 복원을 확대했습니다. 같은 이름의 미검증 글꼴에는 임의 치환을 적용하지 않습니다.
- 숫자·한글 혼합 분수, 오른쪽 위·아래첨자, 질량수만 있는 왼쪽 첨자, 별표 위첨자, 벡터를 보정했습니다. 실제 밑줄과 분수선도 구분합니다.
- 독립 표가 합쳐지거나 중복되는 경우, 표 옆 문장의 읽기 순서, 부분 밑줄과 가장자리 과목명 혼입을 보정했습니다.
- 짧은 자료 상자와 본문 속 작은 사각 빈칸을 복원하고, 빈칸은 DOCX·HWPX의 편집형 수식 테두리로 내보냅니다.
- 작은 원문자의 박스 높이와 수식에 걸친 밑줄 표시, `cal/g·℃` 중점 순서를 보완했습니다. 표 셀의 여러 항목은 실제 줄바꿈으로 표시·저장·내보냅니다.
- 일반 변수의 오른쪽 첨자를 핵종처럼 왼쪽에 옮기거나 중복하는 API 응답을 검사합니다. 핵종 예시는 관련 문맥에서만 추가하며 원문 배치와 수치를 추측으로 바꾸지 않도록 제한합니다.
- 화학 머리글 감지 누락으로 과목 밖 기준이 추천되는 경로를 보정했습니다. 확인된 충격량·전기력·속성 작용·생물 특성·태풍·해파·지형류 문항은 평가 내용에 맞는 후보만 남기며, 적합한 기준이 없으면 판단을 보류합니다. 교사의 수동 과목 선택을 우선합니다.
- DOCX에서 질량수만 있는 핵종의 빈 아래첨자가 네모로 보이거나, 상자 앞에서 끊긴 반응식의 `+` 뒤에 오류 기호가 붙는 뷰어 호환 문제를 보완했습니다. LibreOffice의 작은 수식 박스 테두리 미표시는 여전히 별도 한계입니다.
- 최초 추출과 검토 저장·재열기의 정규화 시점을 맞췄습니다. 기존 검토 파일·수동 수정본·문제함은 자동 덮어쓰지 않습니다.
- 0.7.12의 성취기준별 캡처 이미지 ZIP·문항목록 CSV 기능은 유지합니다.

## 사용 시 유의점

수정 전 결과를 검토 저장으로 백업한 뒤 원본 PDF를 새 버전에서 다시 분석하세요. 모든 PDF의 OCR 정확도나 2015→2022 교육과정 매핑 정확도를 보증하는 업데이트는 아닙니다. 그림·사진·그래프는 원문 캡처를 함께 사용해야 합니다. 실제 API 호출 없이 로컬 PDF·모의 응답으로 검사하며 검증 결과는 [현재 검증 상태](../VALIDATION_STATUS.md)에 구분해 기록합니다.
