# 문항맵 0.7.17 — HWPX 교재 가져오기·정답 연결

- HWPX 본문·표·서식·한글 수식·삽입 그림을 로컬에서 읽습니다. 구형 HWP는 HWPX로 다시 저장해야 합니다.
- 명시된 문항 코드와 문제/정답/해설 표식이 있는 도서를 분리해 최대 1,000문항의 문제은행용 검토 JSON을 만듭니다. 반복 번호는 고유 코드와 단원/쪽 구분으로 보존합니다.
- 정답·해설·문제 그림·해설 그림을 별도 보존하고 PNG/JPEG 및 지원되는 BMP의 무손실 PNG 변환을 지원합니다.
- PDF·HWPX·TXT/CSV 정답 파일을 불러와 미리 대조한 뒤 연결합니다. 중복·모호한 항목과 기존 정답 충돌은 직접 확인해야 합니다.
- 현재 문항과 내 문제함에서 정답을 수정합니다. 문서 내보내기는 정답 기본 제외, 교사용 포함 선택과 별도 정답 CSV를 제공합니다.
- 정답 CSV를 수정해 다시 연결할 수 있도록 원본 문항 코드·번호·구분을 보존합니다. 성취기준 후보 교과를 실제 시험 과목으로 오인해 다른 선택과목의 정답을 연결하지 않습니다.
- HWPX는 원본 페이지 캡처·배치를 재현하지 않습니다. 불확실한 수식은 원문 스크립트를 남기고, 공통 지문 세트·각주/미주·읽지 못한 그림은 누락을 막기 위해 중단합니다.

## 사용과 한계

기존 수정본을 검토 JSON으로 백업한 후 이전 서버를 종료하고 새 ZIP을 별도 폴더에 풀어 실행하세요. Node.js 22.13 이상이 필요하며 기존 문제함과 설정은 보존합니다.

HWPX를 선택한 후 검토 저장으로 JSON을 받으세요. 별도 정답표는 상단 **정답 파일 연결**에서 대조 후 반영합니다. HWPX 분석·정답 연결은 API 없이 로컬 처리합니다. API 이미지 판독과 원문 캡처가 필요하면 PDF를 사용하세요.

자동 추출·수식 변환·성취기준 추천은 초안입니다. 모든 문서 형식이나 수식 의미의 정확성을 보장하지 않으며 원문 확인이 필요합니다. 원본 교재와 생성 JSON은 공개 배포본에 포함하지 않습니다.
