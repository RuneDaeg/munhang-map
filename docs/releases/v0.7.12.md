## 문항맵 0.7.12 — 캡처 이미지 성취기준별 내보내기

> 0.7.12는 로컬 구현·검증 버전이며 별도 공개 ZIP 없이 [0.7.14](./v0.7.14.md)에 포함해 배포합니다.

### 변경 내용

- **내보내기 → 캡처 이미지 구성**에 **성취기준별 폴더 + 매핑 목록 · ZIP**을 추가하고 기본값으로 지정했습니다. **성취기준별 캡처 · ZIP**을 누르면 현재 매핑된 코드·교과별로 캡처를 묶습니다.
- ZIP 최상위 **문항목록.csv**에서 각 이미지의 경로·성취기준 코드와 내용·교과·원본 PDF·문항 번호·캡처 순번·쪽수를 확인할 수 있습니다. 미분류 문항도 별도 폴더에 보존합니다.
- **내 문제함**에서 여러 PDF의 문항을 선택해 같은 방식으로 받을 수 있습니다. 현재 선택/저장된 매핑을 사용하며 API 판독이나 재매핑을 하지 않습니다.
- 기존 이미지 전용 ZIP은 **이미지만 한 폴더 · ZIP** 옵션으로 유지합니다. 캡처 구성은 DOCX/HWPX 파일 구성 설정과 별개입니다.
- JPG/PNG 원본 바이트와 여러 캡처의 순서를 보존합니다. 이미지에 성취기준을 덧그리거나 다시 압축하지 않습니다. 두 모드 모두 문항 본문 텍스트 문서·API 키·원본 전체 페이지를 추가하지 않습니다.
- 캡처 누락은 조용히 제외하지 않고 다운로드를 막아 알립니다. 내보내기 창의 DOCX/HWPX 수식 설명도 현재의 네이티브 수식 변환 동작에 맞게 정정했습니다.

### 사용 및 업데이트

1. 수정본을 **검토 저장**하고 기존 서버를 종료합니다.
2. 이 기능을 포함한 [0.7.14 실행용 ZIP](https://github.com/RuneDaeg/munhang-map/releases/download/v0.7.14/munhang-map-local-0.7.14.zip)을 새 폴더에 전부 압축 해제합니다. `Source code (zip)`과 다릅니다.
3. Node.js 22.13 이상인 지원 중 LTS에서 Mac은 `문항맵.command`, Windows는 `문항맵.bat`를 실행하고 **v0.7.14**를 확인합니다.
4. 저장된 검토 파일이나 문제함의 캡처·매핑을 사용할 수 있습니다. 이번 기능을 위해 유료 API를 다시 호출할 필요는 없습니다. 기존 키·문제함과 이전 릴리스는 유지합니다.

이미지에는 원문 문항과 개인정보가 포함될 수 있고, 매핑 CSV에는 원본 PDF 이름 등이 들어갑니다. 외부 반출 금지 자료를 공유하지 마세요. 기존 인식·매핑 오류를 이번 내보내기 기능이 수정하는 것은 아니므로 결과를 대조해 주세요.

### 당시 로컬 검증 이력

- 회귀 **246/246 통과**, 실패·생략 0. TypeScript·변경 코드의 신규 lint 진단 없음·`git diff --check`·로컬 빌드를 확인했습니다. 기존 테스트 파일의 lint 진단 4개까지 모두 해소한 결과는 아닙니다.
- 배포본의 실제 브라우저 다운로드로, 검토 문항의 성취기준을 직접 변경하면 변경된 코드·전문이 CSV에 담기는 것을 확인했습니다. 문제함 4문항·5캡처는 미분류를 포함한 3폴더로 분리됐고, 모든 이미지 바이트·ZIP CRC가 일치했습니다.
- 기존 단일 폴더 ZIP, 두 구성 설정의 독립성, 캡처 누락 시 차단, PC·375px 모바일 화면을 검사했습니다. 합성 문항과 격리된 임시 데이터만 사용했으며 실제 API 호출·키 설정 조회·외부 요청·콘솔 오류는 0건입니다.
- 배포 ZIP의 UTF-8 이름·Mac 실행 권한 `0755`·필수 파일·개인 자료 제외를 확인했습니다. Windows 실기기 실행이나 수식·지문·매핑 의미의 새로운 전수 검증은 아닙니다.
- 당시 로컬 ZIP을 새 임시 폴더에 압축 해제해 위 브라우저 다운로드를 재검사했고, 로컬 서버의 PDF worker MIME·임시 문제함 저장/재시작·다른 출처 차단 검사도 통과했습니다. 0.7.12 개별 공개판은 게시하지 않았으며 후속 0.7.14 통합 배포와 다운로드 검증은 별도로 기록합니다.

기존 인식 한계는 [현재 검증 상태](https://github.com/RuneDaeg/munhang-map/blob/main/docs/VALIDATION_STATUS.md)에 유지합니다.
