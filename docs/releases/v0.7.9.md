## 문항맵 0.7.9 — PDF 업로드는 로컬 추출, API 판독은 한 문항씩

### 변경 사항

- **PDF를 처음 넣을 때 저장된 API 키가 있어도 AI 판독을 자동 실행하지 않습니다.** 텍스트 추출·문항 분리·문항 전체 캡처·검증된 글꼴과 좌표에 따른 수식 복원·성취기준 후보 추천은 로컬에서 처리합니다. 이 단계에는 AI 공급자 전송이나 API 사용 비용이 없습니다.
- AI 판독이 필요한 문항 하나를 선택한 뒤 **이 문항만 API로 판독**을 누릅니다. 확인창에서 문항 번호·API 공급자와 해당 문항의 이미지·텍스트 전송, 비용 발생 가능성을 확인한 경우에만 요청합니다. 해당 문항에 연결된 공통 지문도 포함될 수 있습니다. 취소하면 API를 호출하지 않으며 다른 문항이나 PDF 전체를 함께 판독하지 않습니다.
- PDF 전체의 자동 AI 판독을 켜는 옵션은 추가하지 않았습니다. API 연결 저장이나 앱 재실행만으로 자동 판독이 켜지지 않습니다.
- 저장된 API 키와 연결 설정은 유지합니다. 같은 OS 사용자·같은 데이터 위치에서는 로컬 추출을 위해 키를 삭제하거나, 한 문항 판독을 위해 키를 다시 입력할 필요가 없습니다.
- 직접 편집한 문항의 덮어쓰기 경고와 API 응답을 기다리는 동안 수정한 내용의 보호를 유지합니다. AI 판독 전 필요한 수정본을 **검토 저장**으로 백업하고 결과를 원문과 대조하세요.
- `0.7.8`의 DOCX/HWPX 네이티브 편집 수식·원문 밑줄·음수 지수 보완과 이전 버전의 표·캡처 이미지 ZIP 개선을 유지합니다. 성취기준 후보 재검색, 수동 수정·저장·내보내기는 AI를 호출하지 않습니다.

### 업데이트 방법

1. **munhang-map-local-0.7.9.zip**을 받습니다. `Source code (zip)`은 실행용 배포본이 아닙니다.
2. 기존 수정본을 **검토 저장**하고 옛 서버를 종료합니다. 새 ZIP을 **새 폴더에 전부 압축 해제**하세요.
3. Node.js **22.13 이상인 지원 중 LTS**에서 Mac은 `문항맵.command`, Windows는 `문항맵.bat`를 실행하고 화면 상단 **v0.7.9**를 확인합니다.
4. PDF를 선택해 로컬 추출 결과를 먼저 확인합니다. 저장된 API 키가 있어도 이 단계에서는 AI를 호출하지 않습니다. 필요한 문항만 위 버튼으로 별도 요청하세요.

이전 릴리스·개인 문제함·API 설정은 보존합니다. 시험지·검토 JSON·개인 문제함·API 키는 배포 ZIP에 포함하지 않습니다. 설치된 폴더는 자동 업데이트되지 않습니다.

### 검증과 제한

- 전체 회귀 테스트 **220/220 통과**, 실패·생략 0. 최초 업로드의 AI 호출 차단과 실제 UI 핸들러의 확인·취소·한 문항 제한·중복 요청·편집 보호 검사를 포함합니다.
- 배포 ZIP을 압축 해제한 뒤 Chromium에서 통합과학 25문항·국어 45문항을 업로드했습니다. API가 연결된 모의 상태에서도 업로드 판독 요청은 **각 0회**입니다. 수동 확인 후에만 선택된 1문항을 요청하고, 취소·키 미연결은 요청하지 않으며, 요청 도중 편집한 내용은 보존합니다. 실제 유료 API는 호출하지 않았습니다.
- TypeScript·변경 파일의 신규 lint 진단 없음·로컬 빌드·ZIP CRC·UTF-8 파일명·Mac 실행 권한·개인 자료 제외를 확인했습니다. 기본 lint의 기존 React/compiler·접근성·Next 이미지 규칙 9건은 남아 있으며 전체 lint 무오류라는 뜻은 아닙니다.
- 로컬 추출은 PDF의 텍스트·글꼴·좌표·선 정보를 사용하는 처리이며 모든 스캔 이미지에 적용되는 OCR은 아닙니다. 스캔형 PDF는 검색 가능한 텍스트 레이어가 필요합니다.
- 로컬 추출·성취기준 추천과 사용자가 요청한 AI 판독은 모두 초안입니다. 원문 의미, 수식, 표 값과 문항 경계는 교사가 대조해야 합니다. API 판독 재시도에도 공급자 비용이 발생할 수 있습니다.
- 전체 검증 범위는 [현재 검증 상태](../VALIDATION_STATUS.md)에 기록합니다. 이전 버전의 검증 결과를 이 버전의 새 검증으로 간주하지 않습니다.
