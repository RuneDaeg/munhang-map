# 문항맵 0.7.21 — HWPX 보기 제목과 내용의 페이지 분리 수정

- HWPX에서 `<보기>` 제목만 앞 페이지에 남고 내용 상자가 다음 페이지로 넘어가던 문제를 수정했습니다.
- 보기·자료표 제목과 상자·표 바로 앞 문장을 다음 내용과 함께 배치합니다. 상자 안에 표가 있는 경우의 제목과 그림을 포함한 제목에도 적용됩니다.
- 일반 본문과 표 셀의 기본 문단 설정은 바꾸지 않습니다. 긴 표의 기존 쪽 나누기, 중첩 표를 연속 구간으로 내보내는 방식, 그림의 삽입 위치·폭·높이 처리는 유지합니다. 문항 전체를 한 페이지에 강제로 넣지 않습니다.

## 검증

- 문제가 있었던 실제 물리 문항 **2개**를 **macOS 한컴오피스 한글 12.30.0**에서 직접 다시 열었습니다. 두 문항 모두 `<보기>` 제목과 내용 상자가 **2페이지에 함께 표시**되며, 표 안의 그림 **4개**는 제 위치에서 잘림·겹침 없이 유지됐습니다.
- 문단 스타일 복제·ID/개수·기존 스타일 보존, 제목/직전 문장 연결, 일반 본문/셀/표 앵커 유지, 중첩 보기와 그림 포함 제목을 검사하는 자동 회귀 **5개**를 추가했습니다.
- 전체 자동 회귀 **515개 통과, 실패 0개**입니다. 별도 실제 PDF 경로가 필요한 선택 검사 15개는 생략했습니다. TypeScript·변경 코드/테스트 lint·로컬 빌드 통과. XML 구조 검사와 실제 한컴 표시 검증을 구분해 확인했습니다.
- 한 셀에 큰 그림 3개가 있는 합성 사례도 한컴에서 다시 열어 모든 그림의 상하 테두리와 표 아래 문장이 온전히 보이는 것을 확인했습니다. 직접 표시 검증은 총 **3파일·7그림**입니다.

## 적용과 제한

기존 서버를 종료하고 새 ZIP을 별도 폴더에 풀어 실행하세요. **기존 검토 JSON·문제함을 열고 HWPX로 다시 내보내면 적용**됩니다. 원본 재분석이나 API 호출은 필요하지 않으며, 이미 다운로드한 HWPX 파일은 자동 변경되지 않습니다. 수동 수정본은 먼저 검토 저장으로 백업하세요.

이번 한컴 검증은 문제가 재현됐던 대표 문항 2개와 합성 사례 1개 대상이며, 전체 교재·Windows 한컴 전수 시각 검증이 아닙니다. 수식 의미나 성취기준 매핑 정확도를 새로 검증한 변경도 아닙니다. 원본 교재·검토 JSON·그림·개인 문제함은 공개 저장소/배포 ZIP에 포함하지 않습니다.
