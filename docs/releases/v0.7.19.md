# 문항맵 0.7.19 — 원문 보존 수식 유형별 변환 확대

- HWPX에서 원문으로 남았던 3,021개 수식을 유형별로 분석하고 **1,105개를 추가 변환**합니다. 명령 대소문자·붙여 쓴 명령, 명시적으로 지원하는 변수 묶음, 독립 숫자 분수, 범위가 명확한 근호·윗줄, 백분율·위첨자 문자·동그라미 문자 처리를 보완했습니다.
- 그리스 문자·화살표·`lim/Lim`처럼 대소문자 의미가 다른 표기는 그대로 구분합니다. 로마체 원소 `In`과 포함 관계 `IN`, `CDOTS`와 `CDOT`를 혼동하지 않도록 보호합니다. 일반 오른쪽 첨자를 핵종 왼쪽 첨자로 바꾸지 않습니다.
- 범위가 모호한 복합 분수·첨자, 미지원 배치 명령 등 **1,916개는 계속 원문으로 보존**합니다. 이 표식은 변환 성공이 아니며 수동 확인이 필요합니다.
- `[삽입 그림: ID]`의 내보내기 동작을 사용법에 명시했습니다. 실제 본문 그림은 DOCX/HWPX의 해당 문항 본문·성취기준 뒤에 첨부되지만 표식도 남고 원래 위치·자르기·회전은 재현하지 않습니다. 해설 그림은 검토 JSON/문제함에 보존되며 현재 문서 내보내기에는 포함하지 않습니다. 기존 이미지 처리 기능의 설명 보완입니다.

## 재검증

- 과학탐구 8권 **2,621문항**의 추출·정답 CSV 재연결·검토 JSON·임시 문제함 저장/새 프로세스 재조회 통과.
- 수식 **34,198개** 대조: 기존 변환 **31,177개 모두 동일**, 추가 1,105개, 최종 변환 32,282개. 새 변환의 KaTeX·DOCX·HWPX 호환 오류 0개.
- 자동 회귀 **480개 통과, 실패 0개**. 별도 PDF 입력을 요구하는 선택 검사 15개는 생략했으며 HWPX 8권 검증은 별도로 모두 실행했습니다. 독립 기대식/원문 보존 구조 검사 51개 통과.
- 실제 ZIP 실행 화면에서 대표 9수식 표시·격리 문제함 저장·DOCX/HWPX 다운로드를 확인했습니다. 대표 DOCX 한 페이지를 렌더링해 확인했습니다. 한컴/Word/Windows 실기기 전수 시각 대조나 모든 문항의 의미·매핑 정확성 인증은 아닙니다.
- 본문 삽입 그림 2,658개의 DOCX/HWPX 첨부 바이트·참조 보존을 검사했습니다. 동일 문항의 반복 그림 참조는 한 번만 첨부하며, 해설 그림 477개는 문서 출력과 별도로 JSON/문제함에서 보존합니다.

## 적용 방법과 남은 제한

기존 서버를 종료하고 새 ZIP을 별도 폴더에 풀어 실행하세요. **수동 수정본을 먼저 백업한 뒤 원본 HWPX를 다시 불러와야** 새 변환이 적용됩니다. 기존 검토 JSON·문제함을 일괄 덮어쓰지 않습니다. Node.js 22.13 이상이 필요하며 이번 변환에는 AI API가 필요하지 않습니다.

`캡처 이미지만 ZIP`은 PDF 문항 캡처용으로, HWPX 삽입 그림을 개별 추출하는 기능이 아닙니다. 원문 배치가 필요하면 PDF 문항 캡처를 사용하세요. 모호한 수식·배치·성취기준은 원문과 대조해야 합니다. 상세 범위는 [현재 검증 상태](../VALIDATION_STATUS.md)를 참고하세요.

원본 교재·정답·해설·검토 JSON·그림·개인 문제함은 공개 저장소나 배포 ZIP에 포함하지 않습니다.
