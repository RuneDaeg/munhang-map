## 문항맵 0.7.11 — API 키 발급 안내·외부 전송 경고

### 변경 내용

- API 연결 화면에서 **OpenAI·Anthropic Claude·Google Gemini**의 키 발급 순서와 공식 콘솔/문서를 펼쳐볼 수 있습니다. 선택한 공급자의 안내가 열리고 다른 공급자 안내도 확인할 수 있습니다.
- 첫 화면과 API 연결 화면 상단에 **외부 반출 금지 문서를 넣지 마세요** 경고를 추가했습니다. 미공개 시험지·출제 중 문항·개인정보·기관 기밀 등의 사용을 주의하도록 안내합니다.
- 개별·전체 API 판독 확인창에도 같은 주의를 표시합니다. 대상 문항 캡처·추출문(공통 지문 포함)이 선택한 AI 공급자 또는 설정한 서버로 전송된다는 점을 명시합니다.
- 최초 PDF 분석은 계속 로컬에서 진행합니다. 키 안내를 보거나 연결을 저장하는 것만으로 API 판독이 시작되지 않습니다. 키의 로컬 보관과 문서의 외부 전송은 별개이며, 이 경고는 반출 금지 여부를 자동 판별하거나 전송을 자동 차단하는 기능이 아닙니다.

### 업데이트 방법

1. 실행용 **munhang-map-local-0.7.11.zip**을 받습니다. `Source code (zip)`은 실행용 배포본이 아닙니다.
2. 수정본을 **검토 저장**으로 백업하고 옛 서버를 종료합니다. 새 폴더에 ZIP을 완전히 압축 해제하세요.
3. Node.js 22.13 이상인 지원 중 LTS에서 Mac은 `문항맵.command`, Windows는 `문항맵.bat`를 실행하고 상단 **v0.7.11**을 확인하세요.

기존 릴리스·문제함·API 설정은 보존합니다. 기존 폴더는 자동 업데이트되지 않습니다. 이번 변경은 키 안내와 전송 경고이며 문항 인식 알고리즘을 추가로 수정한 버전은 아닙니다.
