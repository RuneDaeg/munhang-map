## 문항맵 0.7.10 — 전체 문항 API 판독·핵종 왼쪽 첨자

### 변경 내용

- 기존 **이 문항만 API로 판독**은 유지하고 상단에 **전체 문항 API 판독** 버튼을 추가했습니다. PDF 최초 업로드는 저장된 API 키가 있어도 계속 로컬에서만 처리합니다.
- 전체 판독은 현재 목록 최대 200문항을 한 문항씩 순서대로 요청합니다. 대상 수·공급자·전송 자료·비용·직접 편집 덮어쓰기 안내를 확인한 뒤 실행합니다. 이미 판독한 문항도 다시 요청하므로 추가 비용이 발생할 수 있습니다.
- 완료 수와 현재 요청 문항을 표시하고 **현재 문항 후 중단**을 지원합니다. 진행 중 요청의 비용은 취소되지 않을 수 있습니다. 실패 시 추가 요청을 멈추고 이미 완료된 결과는 유지합니다. 응답 대기 중 직접 수정한 문항은 덮어쓰지 않습니다.
- PDF가 원소 기호와 반응 연산자를 `H +`, `H →`처럼 묶어 저장한 경우에도 원본 좌표에 근거해 왼쪽 위·아래 첨자를 복원합니다. 실제 제공된 물리학Ⅰ 6번에서 핵종 첨자 여섯 쌍을 확인했습니다.
- API 응답에서 원문으로 확인된 핵종 첨자·원소·반복 개수가 사라지거나 바뀌면 기존 텍스트를 유지하고 경고합니다. 원문 전체 발문이 재판독 결과 앞에 중복 붙는 경로도 보완했습니다. 이미지에 없는 숫자를 핵반응 보존 법칙 등으로 추측해 채우지 않습니다.

### 업데이트 방법

1. **munhang-map-local-0.7.10.zip**을 받습니다. `Source code (zip)`은 실행용 배포본이 아닙니다.
2. 기존 수정본을 **검토 저장**으로 백업하고 옛 서버를 종료합니다. ZIP을 새 폴더에 전부 압축 해제하세요.
3. Node.js **22.13 이상인 지원 중 LTS**에서 Mac은 `문항맵.command`, Windows는 `문항맵.bat`를 실행합니다. 화면 상단 **v0.7.10**을 확인하세요.
4. 새 좌표 복원은 **원본 PDF를 다시 선택**해야 적용됩니다. 오래된 검토 파일에는 이미 빠진 첨자의 좌표가 없어 파일을 여는 것만으로 복원되지 않습니다.

기존 릴리스·개인 문제함·API 설정은 보존합니다. 설치된 폴더는 자동 업데이트되지 않습니다. 시험지·검토 JSON·개인 문제함·키는 저장소나 배포 ZIP에 포함하지 않습니다.

### 검증 결과와 남은 한계

- 회귀 테스트 **241/241 통과**, 실패·생략 0. 실제 PDF 좌표, 첨자 보존, API 모의 응답, KaTeX·DOCX·HWPX 첨자 직렬화를 포함합니다. TypeScript·변경 파일의 신규 lint 진단 없음·빌드·ZIP 검사를 통과했습니다. 기존 React/compiler·접근성·Next 이미지 규칙 진단을 모두 없앴다는 뜻은 아닙니다.
- 실제 압축 해제본에서 과탐 8개 PDF **160문항**을 업로드했고 API 판독 POST는 **0회**였습니다. 모의 API로 전체 20문항 순차 요청, 취소 0회, 중단 시 현재 요청 1회, 실패 시 2번에서 정지, 개별 판독·편집 보호·미연결 차단을 확인했습니다. 외부 네트워크 요청과 브라우저 오류는 0건입니다. 실제 유료 API를 호출한 검증은 아닙니다.
- GitHub에 게시된 ZIP을 실제 내려받아 동일한 160문항 브라우저 흐름과 PDF worker MIME·임시 문제함·출처 차단 검사를 다시 통과했습니다. 다운로드 SHA-256: `0c7edad45e83122af080439f87bc35c5bcd0aebcbc609b04ecb7e91a666c007f`. GitHub 자산 해시가 같고 모든 소스/renderer 파일이 로컬 검증본과 일치합니다.
- 8과목 **160문항 모두 원본과 편집 미리보기를 시각 대조**했습니다. 변경 없는 결과는 텍스트·구조·캡처 비교로 재검증했습니다. **69문항에 구체적인 편집 텍스트 결함**, 9문항에 경미한 표시/배치 검토가 남았습니다. 67문항은 추가 결함이 보이지 않아도 자료 그림을 원본 캡처로 함께 써야 합니다. 나머지 15문항에는 이번 대조에서 추가 결함이 관찰되지 않았으며, 이 중 1문항이 왼쪽 첨자 수정 확인 사례입니다. 인식 정확도 백분율이나 전 문항 정상 판정이 아닙니다.
- 미복원 문자 **104개/26문항**, 추출된 260개 수식 영역 중 **8개 문법 오류**가 남습니다. 그 8개는 DOCX/HWPX 변환도 거부합니다. 분수·오른쪽 첨자·병렬 표·밑줄·옆면 과목명 혼입과 일부 과목 밖 성취기준 추천은 추가 개선 대상입니다. 이번 릴리스가 이 모두를 수정한 것은 아닙니다.
- 시험지 머리글의 ‘2022학년도’와 앱 카탈로그의 ‘2022 개정 교육과정’은 다른 뜻입니다. 해당 시험지와 새 교육과정의 성취기준 대응을 전수 승인하지 않았습니다. AI 판독도 정답이나 매핑 정확성을 보증하지 않습니다.
- Windows 실기기와 Word/한글 네이티브 앱에서 160문항 문서를 전부 열어 본 검사는 아닙니다. 전체 범위는 [현재 검증 상태](https://github.com/RuneDaeg/munhang-map/blob/main/docs/VALIDATION_STATUS.md)에 기록합니다.
