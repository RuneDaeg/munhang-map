# 문항맵 0.7.20 — 삽입 그림을 본문 위치에 표시

- HWPX의 `[삽입 그림: ID]` 자리에 **실제 그림**을 표시합니다. 중앙 문항 목록·우측 미리보기·문제함의 보기/수정 미리보기와 DOCX·HWPX에 적용합니다.
- 문장 중간·보기 상자·표 셀에서도 본문의 순서를 유지합니다. 같은 그림을 여러 번 참조하면 각 위치에 표시하며, 연결된 그림을 문항 뒤에 다시 몰아서 붙이지 않습니다.
- 여러 책의 같은 그림 ID가 섞이지 않도록 문항별로 연결합니다. 그림은 비율을 유지하며 본문·셀 폭 안으로 맞추고, HWPX 표에서는 여러 그림의 줄바꿈 높이를 확보합니다.
- 그림 데이터가 없는 표식은 화면에서 경고하고 해당 문서 내보내기를 중단합니다. 위치 표식이 없는 옛 자료는 그림을 잃지 않도록 ‘위치 미지정/삽입 위치 미확인’으로 따로 보존합니다.
- 기존 PDF 원문 캡처·그림 선택지 첨부 방식은 유지합니다. PDF의 표식처럼 생긴 일반 문구는 그림으로 해석하지 않습니다. 그림이 있어도 잘못된 부분 수식 서식을 그대로 내보내지 않도록 검사합니다.

## 검증

- 과학탐구 8권 **2,621문항**, 본문 그림 표식 **2,664곳**의 DOCX·HWPX 위치·앞뒤 본문/수식 순서·그림 바이트를 전수 구조 대조했습니다. 표 셀 **396곳**, 보기 상자 **5곳**, 반복 참조 **6곳** 포함, 해결된 표식의 잔류 **0개**입니다.
- 문항 간 ID 충돌·중첩 보기와 표·누락 그림·반복 개체 ID·셀 폭/높이·굵게/밑줄·기존 PDF 첨부 회귀를 검사했습니다. 검토 JSON과 문제함의 본문·해설·그림 데이터 왕복도 유지됩니다.
- 자동 회귀 **510개 통과, 실패 0개**. 별도 PDF 실자료 경로가 필요한 선택 검사 15개는 생략했으며 HWPX 8권 대조는 별도로 모두 실행했습니다. TypeScript·변경 라이브러리/컴포넌트/테스트 lint·로컬 빌드를 통과했습니다.
- 실제 ZIP 실행 화면에서 HWPX 입력, 본문/보기/표 그림 표시, 격리 문제함 저장과 보기/수정 미리보기, DOCX/HWPX 다운로드를 확인했습니다. 각 다운로드에 표식 대신 그림 5개가 들어감을 확인했고, 합성 대표 및 실제 다운로드한 DOCX를 각 한 페이지씩 렌더링해 문장·표 안의 그림을 확인했습니다.

## 적용과 제한

기존 서버를 종료한 뒤 새 ZIP을 별도 폴더에 풀어 실행하세요. **기존 검토 JSON·문제함에 그림 데이터와 `[삽입 그림: ID]` 표식이 남아 있으면 재분석 없이 적용**됩니다. 편집창에서는 표식을 유지하며, ID를 바꾸지 않고 표식을 옮기면 출력 위치도 바뀝니다. 데이터가 빠진 자료는 원본 HWPX에서 다시 가져와야 합니다. 수동 수정본은 먼저 백업하세요.

이번 개선은 **본문 흐름 안에서의 위치**를 보존하는 기능입니다. 원문 페이지 좌표·떠 있는 개체 배치·그림 자르기/회전·병합 셀 모양을 그대로 재현하지 않습니다. 한컴·Word·Windows 실기기에서 전체 교재를 시각 대조한 검증은 아닙니다. HWPX는 그림 개체·참조·위치·폭/높이와 다시 읽기 검증을 수행했습니다.

해설 그림은 화면 미리보기 및 검토 JSON/문제함에 보존되며, 현재 문서 내보내기의 해설 제외 정책은 유지됩니다. ‘캡처 이미지만 ZIP’은 PDF 문항 캡처용입니다. AI API 없이 동작하며 원본 교재·검토 JSON·그림·개인 문제함은 공개 저장소/배포 ZIP에 포함하지 않습니다.
