# 문항맵

모의고사 PDF에서 텍스트를 추출해 문항별로 나누고, 2022 개정 교육과정 성취기준 후보를 연결한 뒤 DOCX/HWPX로 내보내는 브라우저 기반 교사용 도구입니다.

## 동작 방식

- 기본 PDF 텍스트 추출은 브라우저 안에서 수행하며 원본 파일을 서버에 저장하지 않습니다.
- 텍스트형 PDF는 페이지의 좌표 정보를 이용해 1열·2열 읽기 순서와 문항 번호를 복원합니다.
- 번호가 빠진 편집형 시험지도 오름차순 문항 경계를 인식하며, 잘못 나뉜 문항은 커서 위치에서 나누거나 이전 문항과 합칠 수 있습니다.
- 스캔 이미지 PDF는 현재 OCR 대상임을 명확히 표시하고 예시 결과로 대체하지 않습니다.
- 로컬 API 키가 설정되면 PDF 페이지를 OpenAI 비전 모델로 한 번 더 판독해 깨진 수식·숫자·단위를 KaTeX 호환 LaTeX로 자동 복원합니다.
- 문항에 딸린 그림·그래프·표·회로·지도만 자동 감지해 잘라내고, 감지된 그림자료만 DOCX/HWPX에 첨부합니다. 전체 페이지 캡처는 화면에서 원문 확인용으로만 유지합니다.
- 자동 판독 결과와 직접 입력한 `$...$` 또는 `$$...$$` 형식의 LaTeX를 KaTeX로 즉시 미리보기합니다.
- 성취기준 문구는 원본 CSV에서 읽으며 앱에서 새로 만들거나 수정하지 않습니다.
- 교과를 먼저 고르지 않고 각 문항의 텍스트로 교과 후보와 해당 교과의 성취기준 후보를 차례로 제안합니다.
- HWPX는 검증된 base skeleton의 `secPr`/`colPr`와 스타일을 보존하고, `mimetype`을 첫 번째 무압축 ZIP 엔트리로 패키징합니다.

## 출처와 라이선스

이 저장소에 포함된 제3자 자료와 구현 참고 내역은 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)에 명시했습니다.

## 로컬 실행

```bash
pnpm install
cp .env.example .env.local
# .env.local의 OPENAI_API_KEY= 뒤에 본인의 키 입력
pnpm dev
```

`OPENAI_API_KEY`는 서버 환경에서만 읽으며 브라우저 저장소나 저장소 소스에 포함하지 않습니다. 키를 설정하지 않아도 기본 PDF 문항 추출, 수동 LaTeX 보정, 문항 분리·병합과 내보내기는 사용할 수 있습니다. 자동 인식을 켜면 분석 대상 PDF 페이지 이미지가 설정한 OpenAI API로 전송되며 API 사용량에 따른 비용이 발생할 수 있습니다.
