# 문항맵

모의고사 PDF에서 텍스트를 추출해 문항별로 나누고, 2022 개정 교육과정 성취기준 후보를 연결한 뒤 DOCX/HWPX로 내보내는 브라우저 기반 교사용 도구입니다.

## 동작 방식

- PDF 처리는 브라우저 안에서 수행하며 원본 파일을 서버에 저장하지 않습니다.
- 텍스트형 PDF는 페이지의 좌표 정보를 이용해 줄과 문항 번호를 복원합니다.
- 스캔 이미지 PDF는 현재 OCR 대상임을 명확히 표시하고 예시 결과로 대체하지 않습니다.
- 성취기준 문구는 원본 CSV에서 읽으며 앱에서 새로 만들거나 수정하지 않습니다.
- HWPX는 검증된 base skeleton의 `secPr`/`colPr`와 스타일을 보존하고, `mimetype`을 첫 번째 무압축 ZIP 엔트리로 패키징합니다.
