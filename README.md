# 문항맵

모의고사 PDF에서 텍스트를 추출해 문항별로 나누고, 2022 개정 교육과정 성취기준 후보를 연결한 뒤 DOCX/HWPX로 내보내는 브라우저 기반 교사용 도구입니다.

## 동작 방식

- 기본 PDF 텍스트 추출은 브라우저 안에서 수행하며 원본 파일을 서버에 저장하지 않습니다.
- 텍스트형 PDF는 페이지의 좌표 정보를 이용해 1열·2열 읽기 순서와 문항 번호를 복원합니다.
- 번호가 빠진 편집형 시험지도 오름차순 문항 경계를 인식하며, 잘못 나뉜 문항은 커서 위치에서 나누거나 이전 문항과 합칠 수 있습니다.
- 스캔 이미지 PDF는 현재 OCR 대상임을 명확히 표시하고 예시 결과로 대체하지 않습니다.
- 시험지 머리말에서 과목명을 감지해 관련 교과의 성취기준으로 후보 범위를 좁힙니다. 예를 들어 ‘통합과학’은 통합과학1·2를 대상으로 하며, 교과서 개정 전 과목명은 관련 2022 교과 후보에 연결할 뿐 동일한 성취기준으로 단정하지 않습니다. 후속 페이지에 과목명이 없으면 직전 페이지의 과목 정보를 이어받습니다.
- API 키 없이도 문항 번호부터 같은 단의 다음 문항 번호 앞까지 원문 전체를 캡처합니다. 그림 위 간접 발문, 그림·표·자료, 아래 직접 발문과 선택지가 포함됩니다. 공통 지문과 다음 단·페이지로 이어지는 내용은 조각별로 순서대로 보존합니다.
- 문항 전체 캡처는 검토 화면과 DOCX/HWPX에 첨부합니다. 번호를 찾지 못하면 페이지 전체를 보존하고 범위 확인 안내를 표시합니다. 수동 텍스트 분리는 원문 캡처의 위치를 임의로 바꾸지 않으며 분리 전 범위임을 표시합니다.
- 각 문항의 ‘캡처 범위 수정’에서 원문 위 사각형을 이동·크기 조절하거나 새 범위를 드래그할 수 있습니다. 키보드로 네 경계의 비율을 입력할 수도 있습니다. 페이지를 바꾸거나 이어지는 캡처 조각을 추가한 뒤 ‘이 범위로 확정’을 누르면 미리보기와 문서 첨부에 반영됩니다. 수정은 텍스트 자체를 바꾸지 않으며 필요한 경우 별도로 재판독합니다.
- ‘검토 저장’은 원문 페이지, 문항 텍스트, 과목 정보, 확정한 캡처 좌표를 로컬 JSON 파일로 저장합니다. ‘검토 파일 열기’로 다시 이어서 수정할 수 있고, API 키나 연결 정보는 포함하지 않습니다. 검토 파일에 시험지 내용이 포함되므로 필요한 상대에게만 직접 공유해 주세요. 수정 좌표는 다음 알고리즘 개선 시 비교 자료로 사용할 수 있으며, 자동 학습이나 외부 업로드는 수행하지 않습니다.
- 로컬 API 연결이 설정되면 문항 전체 캡처를 선택한 비전 모델로 판독해 깨진 수식·숫자·단위를 KaTeX 호환 LaTeX로 복원합니다. AI가 반환한 그림 좌표는 원문 캡처를 덮어쓰지 않습니다.
- 자동 판독 결과와 직접 입력한 `$...$` 또는 `$$...$$` 형식의 LaTeX를 KaTeX로 즉시 미리보기합니다.
- 성취기준 문구는 원본 CSV에서 읽으며 앱에서 새로 만들거나 수정하지 않습니다.
- 교과를 먼저 고르지 않고 시험지 과목 정보와 문항 텍스트로 후보를 제안합니다. 수동으로 선택한 교과는 텍스트 재분류와 AI 재인식 후에도 유지합니다.
- HWPX는 검증된 base skeleton의 `secPr`/`colPr`와 스타일을 보존하고, `mimetype`을 첫 번째 무압축 ZIP 엔트리로 패키징합니다.

## 설치 없이 로컬 브라우저에서 실행

`pnpm local:package`로 만든 `release/문항맵-로컬` 폴더를 사용하면 됩니다. Node.js 22 이상이 설치된 컴퓨터에서 Mac은 `문항맵.command`, Windows는 `문항맵.bat`를 실행하면 기본 브라우저에 `127.0.0.1` 전용 화면이 열립니다. 외부 컴퓨터에서는 접속할 수 없습니다.

- OpenAI, Anthropic Claude, Google Gemini를 직접 선택할 수 있습니다.
- Ollama, LM Studio 및 다른 서비스는 OpenAI Chat Completions 호환 `/v1` 주소로 연결할 수 있습니다.
- Mac의 API 키는 macOS 키체인에 저장되며 브라우저 저장소에는 남기지 않습니다.
- 화면에는 공급자, 모델, 키 끝 4자리, 이 문항맵에서 사용한 입력·출력 토큰과 추정 사용액이 표시됩니다.
- 사용자가 월 예산과 모델 단가를 입력하면 앱이 추정 잔액을 계산합니다. 이는 공급자의 실제 청구 잔액이 아니라 이 앱에서 관측한 사용량 기준입니다.

개발 중인 소스에서 바로 실행하려면 다음 명령을 사용합니다.

```bash
pnpm install
pnpm local
```

단일 `file://` HTML에 키를 직접 저장하는 구성은 제공하지 않습니다. 그 방식은 키가 브라우저 저장소와 개발자 도구에 노출되고 공급자별 CORS 정책 때문에 일부 API가 동작하지 않습니다. 로컬 서버 방식도 자동 인식을 켜면 분석 대상 PDF 페이지 이미지가 선택한 API 공급자에게 전송되며 사용량에 따른 비용이 발생할 수 있습니다.

## 데스크톱 앱

Electron 데스크톱 앱에서도 같은 공급자와 모델을 선택할 수 있습니다. 입력한 연결 정보는 운영체제 보안 저장소로 암호화되고 브라우저 저장소나 문항맵 서버에는 전송되지 않습니다.

```bash
# 현재 Mac용 DMG 생성
pnpm desktop:mac

# 64비트 Windows용 설치 EXE 생성
pnpm desktop:win
```

생성된 설치 파일은 `release/` 폴더에 저장됩니다. `.github/workflows/desktop-build.yml`은 macOS와 Windows에서 각각 설치 파일을 생성해 Actions 아티팩트로 보관합니다. 배포용 설치 파일에는 별도의 Apple Developer 서명·공증 및 Windows 코드 서명을 적용하는 것을 권장합니다.
