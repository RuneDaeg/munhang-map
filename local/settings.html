외부 반출 금지 문서를 넣지 마세요

미공개 시험지·출제 중 문항·개인정보·기관 기밀 등 외부 전송이 금지된 자료는 사용하지 마세요. API 판독을 실행하면 문항 캡처 이미지·추출 텍스트·공통 지문이 선택한 AI 공급자 또는 설정한 서버로 전송됩니다.

PDF 최초 분석은 로컬에서 진행되며, 개별·전체 문항 API 판독을 확인한 뒤 전송됩니다. API 키를 내 컴퓨터에 저장해도 문서의 외부 전송을 막아 주지는 않습니다. 이 경고는 문서의 반출 금지 여부를 자동 판별하거나 전송을 차단하는 기능이 아닙니다.

AI 공급자 연결

API 키는 브라우저 저장소가 아닌 이 컴퓨터의 문항맵 로컬 서버가 관리합니다. 실제 저장 방식은 오른쪽 ‘저장 위치’에서 확인하세요. 연결 저장만으로 문서가 API로 전송되지는 않습니다.

API 키 발급 방법

처음 연결하시나요? 공급자를 선택하면 해당 안내가 열립니다. 다른 공급자 안내도 눌러서 펼칠 수 있습니다. 아래 공식 사이트 링크는 새 탭에서 열립니다.

OpenAI API 키 발급
  1. OpenAI API 키 관리에 로그인합니다. 계정이 없다면 가입합니다.
  2. 사용할 프로젝트의 API keys 화면에서 새 API 키를 만들고 복사합니다.
  3. 이 화면에서 공급자를 OpenAI로 선택하고, 아래 API 키 입력란에 붙여 넣습니다. 모델·사용 예산을 확인한 뒤 연결 저장을 누릅니다.

OpenAI Docs · 공식 시작 안내

Anthropic Claude API 키 발급
  1. Claude Console API 키 관리에 로그인하고, Settings → API keys → Create key로 이동합니다.
  2. 키 이름과 만료 기간을 정합니다. 개인용은 Linked account에서 본인을 선택하고, 사용할 워크스페이스 하나로 범위를 지정한 키를 만듭니다.
  3. 키를 복사하고 이 화면에서 Anthropic Claude를 선택합니다. 아래 API 키 입력란에 붙여 넣고 모델·사용 예산을 확인한 뒤 연결 저장을 누릅니다.

문항맵은 워크스페이스 ID를 별도로 입력받지 않으므로, 워크스페이스가 지정된 키를 사용하세요.

Claude · 공식 인증 안내

Google Gemini API 키 발급
  1. Google AI Studio API 키 관리에 Google 계정으로 로그인하고 필요한 약관을 확인합니다.
  2. 사용 권한이 있는 Google Cloud 프로젝트를 선택하거나 만듭니다. 기존 프로젝트가 보이지 않으면 Dashboard → Projects → Import projects에서 가져옵니다.
  3. API Keys에서 Create API key로 키를 만들고 복사합니다. 이 화면에서 Google Gemini를 선택해 아래 API 키 입력란에 붙여 넣고, 모델·사용 예산을 확인한 뒤 연결 저장을 누릅니다.

키 생성 버튼이 없거나 권한 오류가 나면 프로젝트·기관 관리자에게 문의하세요. 오래된 키가 차단되면 공식 안내의 키 전환 절차를 확인하세요.

Gemini · 공식 API 키 안내

API 키는 비밀번호처럼 관리하고 채팅·스크린샷·GitHub에 공개하지 마세요. 유출이 의심되면 공급자 콘솔에서 키를 폐기하고 새 키로 교체하세요. 요금·무료 할당·결제 필요 여부는 공급자 콘솔에서 직접 확인해 주세요.

공식 문서 확인: 2026-09-12 · 메뉴 이름과 발급 절차는 공급자 변경에 따라 달라질 수 있습니다.

기본 단가는 참고값이며 모델·요금제에 따라 달라질 수 있습니다. 공급자 가격표와 맞는지 확인해 주세요.
