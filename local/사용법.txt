문항맵 로컬 실행 0.7.2

1. Node.js 22.13 이상 LTS 버전을 설치합니다: https://nodejs.org
2. Mac은 “문항맵.command”, Windows는 “문항맵.bat”를 실행합니다.
   Mac에서 “확인할 수 없는 개발자” 안내로 열리지 않으면 “문항맵.command”를 우클릭 → 열기 → 열기를 처음 한 번만 해 주세요.
3. PDF를 넣거나 ‘검토 파일 열기’를 누릅니다. AI 판독을 사용할 때만 API 공급자와 키를 설정합니다.
4. 실행 중인 터미널 창을 닫으면 로컬 문항맵도 종료됩니다.

문항 추출
- 텍스트형 PDF의 머리말에서 시험 과목을 읽어 성취기준 후보에 반영합니다.
- 발문, 그림·표·자료, 질문과 선택지를 포함한 문항 전체 캡처는 API 키 없이 생성됩니다.
- 문항 전체 캡처는 DOCX/HWPX에도 첨부됩니다. 경계 확인 안내가 있는 문항은 원문과 비교해 주세요.
- ‘캡처 범위 수정’에서 상자를 끌거나 모서리를 조절한 뒤 ‘이 범위로 확정’을 누르세요.
- ‘검토 저장’으로 수정한 결과를 파일로 보관하고, 다음에는 ‘검토 파일 열기’로 이어서 수정할 수 있습니다.
- 검토 파일에는 시험지 원문이 포함되며 API 키는 포함되지 않습니다.
- 일반 문장은 평문, 실제 수식만 $…$로 입력합니다. AI 판독도 이 형식으로 요청합니다.
- 수식 바깥의 \bullet, \circ, \times, \rightarrow 같은 기호도 표시합니다. 문항 목록에도 수식이 렌더링됩니다.
- 넓은 화면에서는 오른쪽 문항 정보가 스크롤을 따라옵니다. 내용이 길면 패널 안에서 스크롤하세요. 다른 문항을 선택하면 패널 내부 스크롤이 처음으로 돌아갑니다.
- 이미 깨진 문장은 ‘텍스트 표기 정리’로 불필요한 text 표기와 탭을 정리할 수 있습니다. API를 사용하지 않습니다.
- 검토 파일을 열거나 문서로 내보낼 때에도 같은 정리가 적용됩니다. 수식 미리보기는 KaTeX이며, DOCX/HWPX에는 수식의 LaTeX 원문과 문항 캡처를 보존합니다.
- 스캔형 PDF는 먼저 OCR 처리가 필요합니다.

영어 발문·선택지 번호 보존
- AI에게 한국어 발문, 영어 지문 전체, 선택지 문장과 원문 번호를 각각 보존하도록 요청합니다.
- 원문 추출문에 선택지 번호가 있거나 AI가 별도 선택지 배열을 반환하면 번호와 문장의 대응을 확인해 ①~⑤와 줄바꿈을 복원합니다. 어법 문제의 지문 내부 번호는 원래 위치에 남깁니다.
- 선택지 누락 또는 번호 감소를 감지하면 기존 내용을 보존하고 경고합니다. 근거 없는 평문을 임의로 5개로 나누지는 않습니다.
- 이미 번호가 없는 결과는 먼저 ‘검토 저장’으로 백업하고, 최신 버전에서 원문 캡처 범위를 확인한 뒤 ‘문항 전체에서 발문·수식 다시 판독’을 누르세요. 재판독은 연결한 API 사용 비용이 발생할 수 있습니다.

숫자·수식 글자가 네모로 보일 때
- 0.7.2는 검증된 HyhwpEQ·HancomEQN 글꼴의 숫자·변수·분수·루트·첨자를 API 없이 복원합니다. 글꼴 이름뿐 아니라 실제 글자 모양도 확인합니다. 표 경계와 다른 기준선을 넘지 않고 흩어진 숫자를 묶습니다.
- 미복원 문자가 하나라도 남으면 해당 문항에 ‘문자 복원 확인 필요’와 개수가 표시됩니다. 성취기준 %는 문자 인식 정확도가 아닙니다.
- 수동 수정본은 먼저 ‘검토 저장’으로 백업하고, 새 버전을 실행한 뒤 원본 PDF를 다시 넣으세요. 새 PDF는 현재 분석 목록을 바꿉니다. 기존 검토 파일이나 문제함에는 글꼴 정보가 없으므로 그것만 열어서는 예전 깨짐이 복원되지 않습니다.
- 미지원 글꼴과 복잡한 수식 배치는 원문을 대조해 수정하거나 이미지 판독 API를 이용하세요. 기본 문자 복원과 AI 재판독은 다릅니다. AI 요청에는 비용이 발생할 수 있습니다.

표·자료 상자·보기
- PDF 내부의 텍스트 좌표와 테두리 선으로 API 호출 전에 표·상자를 복원합니다. 짧게 나뉜 선, <보기> 제목으로 끊긴 윗선, 바깥 세로선이 없는 표도 처리합니다.
- 선택지 표는 ① 위의 머리글과 각 열을 함께 포함합니다. 여러 줄 제목, 영어 (A)/(B), 표 바깥의 번호도 확인합니다. 넓은 표는 가로 스크롤하세요.
- AI 재판독이 기존 표·상자나 머리글을 누락하면 원래 구조를 보존하고 경고합니다.
- 이미지 입력 가능한 API를 연결하면 AI 판독 단계에서 표와 자료 상자도 함께 인식하도록 요청합니다.
- 문장 자료와 <보기>는 각각 한 칸짜리 표로, 행·열 자료는 여러 셀의 표로 DOCX/HWPX에 넣습니다.
- 상자 밖 발문·질문·선택지는 표 밖에 유지하며, 문항 전체 캡처도 계속 첨부합니다.
- 명확한 <보기> 제목·ㄱ/ㄴ 항목·①/② 선택지 경계가 있으면 AI 표식이 없어도 로컬 규칙으로 상자를 묶습니다. 공백과 항목 중간 줄바꿈도 처리하며 추가 API 비용은 없습니다. 예전 검토 파일이나 문제함을 열어도 적용됩니다.
- 새 좌표 알고리즘을 적용하려면 수정본을 먼저 검토 저장한 뒤 PDF를 다시 선택하세요. 예전 검토 파일만 열면 PDF의 선 정보를 다시 읽을 수 없습니다. ‘문항 전체에서 발문·수식 다시 판독’은 AI 요청으로 추가 비용이 발생할 수 있습니다.
- 입력칸 아래 ‘자료 상자 삽입’, ‘보기 상자 삽입’, ‘자료표 삽입’으로 직접 만들 수도 있습니다. API 없이 사용할 수 있습니다.
- :::box 또는 :::table로 시작하고 마지막 별도 줄의 :::로 닫습니다. 표 행은 |로 시작·종료하며 모든 행의 열 수를 맞춥니다. 잘못된 구조는 텍스트로 보존합니다.
- ‘문항 미리보기 · 수식·표·보기’는 원문 캡처 아래, 텍스트 편집창 위에 있습니다. 상자·표 개수를 확인하고 텍스트 편집칸에서 수정하세요. 저장·문제함·성취기준별 내보내기에도 구조가 유지됩니다.
- 화면 상단 문항맵 옆에 v0.7.2이 표시되는지 확인하세요. 옛 서버를 종료하고 새 폴더의 실행 파일을 여세요.
- 로컬 선 분석은 텍스트형 PDF 대상이며 스캔 이미지의 모든 박스를 찾는 기능은 아닙니다. 작은 표와 상자 안의 여러 표를 함께 보존합니다. 좌우 두 묶음의 선택지는 머리글이 같을 때만 한 표로 합칩니다.
- DOCX는 상자 안의 표를 중첩된 편집형 표로 보존합니다. HWPX는 표 잘림 위험을 줄이기 위해 바깥 설명 상자와 내부 표를 같은 폭의 연속 구간으로 출력하므로 외곽선이 원문과 다를 수 있습니다. 한컴 앱의 실제 표시 결과는 확인이 필요합니다.
- 병합 셀은 일반 격자로 풀어 표현합니다. 셀 안 그림·원본과 동일한 크기는 지원하지 않으므로 원문 캡처와 대조하세요. 비정형 그림 선택지는 번호를 포함한 원본 이미지로 보존하고 확인 안내를 표시합니다.
- 직접 편집한 문항을 API로 재판독하기 전에는 확인을 받습니다. 재판독 응답을 기다리는 동안 수정한 내용은 덮어쓰지 않습니다.

분석 진행과 내보내기
- PDF 읽기, 문항 분리·캡처, 발문·수식 판독, 성취기준 분류가 끝날 때까지 진행 화면을 유지합니다.
- API 연결이 없으면 AI 판독 생략, 일부 문항의 판독 실패가 있으면 원문 보존 안내가 표시됩니다.
- ‘문서 내보내기’에서 성취기준마다 DOCX/HWPX 파일을 나눈 ZIP을 받을 수 있습니다. 원본 PDF·문항 번호 목록도 포함됩니다.

굵게·밑줄
- 오른쪽 텍스트 편집창에서 글자를 선택하고 Mac은 Cmd+B/U, Windows는 Ctrl+B/U를 누릅니다. B 굵게/U 밑줄 버튼도 사용할 수 있습니다. 다시 누르면 해제합니다.
- LaTeX를 쓰지 않아도 되며, 검토 저장·문제함·DOCX/HWPX 내보내기에 글자 서식이 유지됩니다.
- 표·박스 경계 표식에는 서식이 적용되지 않습니다. 외부 붙여넣기는 텍스트만 가져옵니다. AI 재판독 전에 수동 수정본을 백업하세요.

내 문제함
- PDF 분석 후 ‘문제함에 저장’을 누르면 현재 PDF의 모든 문항과 캡처를 이 컴퓨터에 저장합니다.
- 같은 이름·원문의 PDF를 다시 저장하면 그 PDF의 기존 저장본을 최신 수정본으로 갱신합니다.
- ‘내 문제함’에서 여러 PDF의 문항을 검색·선택하고 함께 내보낼 수 있습니다. 저장된 문항을 다시 AI 분석하지 않으므로 API 비용은 없습니다.
- 앱을 종료하거나 새 버전으로 실행해도 문제함은 유지됩니다. API 키는 문제함에 포함되지 않습니다.
- 백업은 앱 종료 후 Mac의 Library/Application Support/문항맵-로컬/question-bank, Windows의 %LOCALAPPDATA%/문항맵-로컬/question-bank 폴더를 복사하면 됩니다.
- 문제함 파일은 암호화하지 않으며 시험지 텍스트와 이미지가 포함됩니다. 다른 사람과 공유할 때 주의하세요.
- 한 번에 200문항까지 선택할 수 있습니다. 큰 문항 묶음은 나누어 내보내세요.

보안 안내
- 웹 서버는 외부 네트워크가 아닌 127.0.0.1에만 열립니다.
- Mac의 API 키는 macOS 키체인에 저장됩니다.
- Windows/Linux는 키를 암호화 파일에 보관하지만 복호화용 파일이 같은 폴더에 있어 키체인 수준의 보호는 아닙니다. 공용 PC에서는 사용 후 키를 지우세요.
- API 키 전체 값은 문항맵 화면에 다시 표시되지 않습니다.
- 자동 판독 사용 시 문항 캡처 이미지는 선택한 AI 공급자에게 전송됩니다.
- 표시되는 사용액과 잔액은 이 문항맵에서 관측한 토큰과 입력한 단가·예산으로 계산한 추정치입니다.
