문항맵 로컬 실행

1. Node.js 22 이상 LTS 버전을 설치합니다: https://nodejs.org
2. Mac은 “문항맵.command”, Windows는 “문항맵.bat”를 실행합니다.
3. PDF를 넣거나 ‘검토 파일 열기’를 누릅니다. AI 판독을 사용할 때만 API 공급자와 키를 설정합니다.
4. 실행 중인 터미널 창을 닫으면 로컬 문항맵도 종료됩니다.

문항 추출
- 텍스트형 PDF의 머리말에서 시험 과목을 읽어 성취기준 후보에 반영합니다.
- 발문, 그림·표·자료, 질문과 선택지를 포함한 문항 전체 캡처는 API 키 없이 생성됩니다.
- 문항 전체 캡처는 DOCX/HWPX에도 첨부됩니다. 경계 확인 안내가 있는 문항은 원문과 비교해 주세요.
- ‘캡처 범위 수정’에서 상자를 끌거나 모서리를 조절한 뒤 ‘이 범위로 확정’을 누르세요.
- ‘검토 저장’으로 수정한 결과를 파일로 보관하고, 다음에는 ‘검토 파일 열기’로 이어서 수정할 수 있습니다.
- 검토 파일에는 시험지 원문이 포함되며 API 키는 포함되지 않습니다.
- 일반 문장은 평문, 실제 수식만 $…$로 입력합니다. AI 판독도 이 형식으로 요청합니다.
- 수식 바깥의 \bullet, \circ, \times, \rightarrow 같은 기호도 표시합니다. 문항 목록에도 수식이 렌더링됩니다.
- 넓은 화면에서는 오른쪽 문항 정보가 스크롤을 따라옵니다. 내용이 길면 패널 안에서 스크롤하세요. 다른 문항을 선택하면 패널 내부 스크롤이 처음으로 돌아갑니다.
- 이미 깨진 문장은 ‘텍스트 표기 정리’로 불필요한 text 표기와 탭을 정리할 수 있습니다. API를 사용하지 않습니다.
- 검토 파일을 열거나 문서로 내보낼 때에도 같은 정리가 적용됩니다. 수식 미리보기는 KaTeX이며, DOCX/HWPX에는 수식의 LaTeX 원문과 문항 캡처를 보존합니다.
- 스캔형 PDF는 먼저 OCR 처리가 필요합니다.

분석 진행과 내보내기
- PDF 읽기, 문항 분리·캡처, 발문·수식 판독, 성취기준 분류가 끝날 때까지 진행 화면을 유지합니다.
- API 연결이 없으면 AI 판독 생략, 일부 문항의 판독 실패가 있으면 원문 보존 안내가 표시됩니다.
- ‘문서 내보내기’에서 성취기준마다 DOCX/HWPX 파일을 나눈 ZIP을 받을 수 있습니다. 원본 PDF·문항 번호 목록도 포함됩니다.

내 문제함
- PDF 분석 후 ‘문제함에 저장’을 누르면 현재 PDF의 모든 문항과 캡처를 이 컴퓨터에 저장합니다.
- 같은 이름·원문의 PDF를 다시 저장하면 그 PDF의 기존 저장본을 최신 수정본으로 갱신합니다.
- ‘내 문제함’에서 여러 PDF의 문항을 검색·선택하고 함께 내보낼 수 있습니다. 저장된 문항을 다시 AI 분석하지 않으므로 API 비용은 없습니다.
- 앱을 종료하거나 새 버전으로 실행해도 문제함은 유지됩니다. API 키는 문제함에 포함되지 않습니다.
- 백업은 앱 종료 후 Mac의 Library/Application Support/문항맵-로컬/question-bank, Windows의 %LOCALAPPDATA%/문항맵-로컬/question-bank 폴더를 복사하면 됩니다.
- 문제함 파일은 암호화하지 않으며 시험지 텍스트와 이미지가 포함됩니다. 다른 사람과 공유할 때 주의하세요.
- 한 번에 200문항까지 선택할 수 있습니다. 큰 문항 묶음은 나누어 내보내세요.

보안 안내
- 웹 서버는 외부 네트워크가 아닌 127.0.0.1에만 열립니다.
- Mac의 API 키는 macOS 키체인에 저장됩니다.
- API 키 전체 값은 문항맵 화면에 다시 표시되지 않습니다.
- 자동 판독 사용 시 문항 캡처 이미지는 선택한 AI 공급자에게 전송됩니다.
- 표시되는 사용액과 잔액은 이 문항맵에서 관측한 토큰과 입력한 단가·예산으로 계산한 추정치입니다.
